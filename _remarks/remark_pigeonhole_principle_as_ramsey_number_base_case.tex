The pigeonhole principle can be viewed as the base case of Ramsey theory. The statement $R(2,k) = k$ says that among any $k$ vertices, either there is an edge (two "pigeons" in one "hole") or all vertices are mutually non-adjacent (an independent set of size $k$). Thus Ramsey theory generalizes the pigeonhole principle from pairs to arbitrary clique sizes.
\end{remark}
