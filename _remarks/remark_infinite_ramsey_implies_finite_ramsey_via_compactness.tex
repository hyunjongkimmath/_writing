The finite Ramsey theorem can be deduced from the infinite version via a compactness argument. If $R(r,s)$ did not exist, then for each $N$ there would be a 2-coloring of $K_N$ with no monochromatic $K_r$ or $K_s$. These colorings form an infinite tree under restriction, and by Konig's lemma, there is an infinite path — yielding an infinite coloring with no finite monochromatic clique of size $r$ or $s$, contradicting \CrefAndHyperrefIfExist{theorem:infinite_ramseys_theorem_for_countable_complete_graph_edge_colorings}{the infinite Ramsey theorem}. Thus the two formulations are logically equivalent.
