For any \CrefAndHyperrefIfExist{definition:simple_graph_directed_graph_multigraph_weighted_graph}{simple graph} $G$, the inequality $\alpha(G) \cdot \chi(G) \geq |V(G)|$ holds. This follows because each color class in a proper vertex coloring is an independent set, so the vertices are partitioned into $\chi(G)$ sets each of size at most $\alpha(G)$. Equality holds for perfect graphs, but this notion lies beyond the scope of these notes.
