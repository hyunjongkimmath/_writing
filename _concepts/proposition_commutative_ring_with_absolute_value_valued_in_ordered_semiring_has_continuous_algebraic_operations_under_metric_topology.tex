\begin{proposition} \label{proposition:commutative_ring_with_absolute_value_valued_in_ordered_semiring_has_continuous_algebraic_operations_under_metric_topology}
    Let $R$ be a \CrefAndHyperrefIfExist{definition:commutative_ring}{commutative ring} equipped with an \CrefAndHyperrefIfExist{definition:absolute_value_on_a_ring_valued_in_an_ordered_semiring}{absolute value valued in an ordered semiring} $|\cdot| : R \to T$, and equip $R$ with the topology induced by the \CrefAndHyperrefIfExist{definition:metric_induced_by_an_absolute_value_on_a_commutative_ring}{metric} $d(a,b) = |a - b|$ \CrefIfExists{definition:topology_on_a_field_induced_by_an_absolute_value}.

    Then the following maps are continuous with respect to this topology:
    \begin{enumerate}
        \item The negation map $\nu : R \to R$, defined by $\nu(a) = -a$.
        \item The addition map $\alpha : R \times R \to R$, defined by $\alpha(a,b) = a + b$ (where $R \times R$ carries the product topology).
        \item The multiplication map $\mu : R \times R \to R$, defined by $\mu(a,b) = ab$.
    \end{enumerate}

    Consequently, the subtraction map $\sigma : R \times R \to R$, defined by $\sigma(a,b) = a - b$, is also continuous because it equals $\alpha \circ (\id_R, \nu)$ where $(\id_R, \nu)(a,b) = (a, -b)$.
\end{proposition}

    Next we show that the addition map $\alpha(a,b) = a + b$ is continuous on $R \times R$. We distinguish two cases based on the structure of $T_{>0}$.

    If $T_{>0}$ has no minimal element (i.e.\ $T$ is \CrefAndHyperrefIfExist{definition:archimedean_ordered_monoid_dense_at_zero_ordered_monoid}{dense at zero}), then for every $\varepsilon \in T_{>0}$ there exists $\delta \in T_{>0}$ such that $\delta + \delta < \varepsilon$. Then for any $(x,y) \in B(a, \delta) \times B(b, \delta)$, we have by subadditivity of $|\cdot|$:
    $$d(\alpha(x,y), \alpha(a,b)) = |(x+y) - (a+b)| = |(x-a) + (y-b)| \leq |x-a| + |y-b| < \delta + \delta < \varepsilon.$$
    Thus $\alpha(B(a, \delta) \times B(b, \delta)) \subseteq B(a+b, \varepsilon)$, so the preimage of $B(a+b, \varepsilon)$ is a neighborhood of $(a,b)$ in the product topology. Since $(a,b)$ was arbitrary, $\alpha$ is continuous.

    If $T_{>0}$ has a minimal element $m$, then for any distinct $x, y \in R$ we have $d(x,y) = |x-y| \geq m$. This means the open ball $B(x, m)$ contains only $x$ itself, so every singleton $\{x\}$ is open and the topology on $R$ is discrete. In the discrete topology every map is continuous, so $\alpha$ is trivially continuous.

    Finally we show that the multiplication map $\mu(a,b) = ab$ is continuous. We use the identity
    $$xy - ab = x(y-b) + (x-a)b,$$
    which gives by subadditivity and multiplicativity:
    $$|xy - ab| \leq |x| \cdot |y-b| + |x-a| \cdot |b|.$$

    In the case that $T_{>0}$ has a minimal element, the topology is discrete and $\mu$ is trivially continuous. Assume therefore that $T$ is dense at zero. Fix $(a,b) \in R \times R$ and let $\varepsilon \in T_{>0}$. We need to find a neighborhood of $(a,b)$ on which $|xy - ab| < \varepsilon$.
