\begin{proposition} \label{proposition:weight_structure_on_a_triangulated_category_is_bounded_if_and_only_if_it_belongs_to_some_lower_bounded_and_upper_bound_weights}
Let $\mathcal{D}$ be a \CrefAndHyperrefIfExist{definition:triangulated_category}{triangulated category} equipped with a \CrefAndHyperrefIfExist{definition:weight_structure_on_a_triangulated_category}{weight structure} $w$. 
The weight structure is \CrefAndHyperrefIfExist{definition:bounded_weight_structure_on_a_triangulated_category}{bounded} if and only if for every object $X \in \mathcal{D}$, there exist integers $a, b \in \mathbb{Z}$ such that $X \in \mathcal{D}_{w \leq a} \cap \mathcal{D}_{w \geq b}$.
\end{proposition}
