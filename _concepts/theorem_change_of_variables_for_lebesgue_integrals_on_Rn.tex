$$\int_V f(y)\,d\lambda^n(y) = \int_U f(\Phi(x))\,|\det D\Phi(x)|\,d\lambda^n(x),$$

If $f : V \to \overline{\mathbb{R}}$ is Lebesgue integrable, then the same equality holds, with both sides finite.
\end{theorem}
