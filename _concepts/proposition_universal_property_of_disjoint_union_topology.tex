\begin{proposition}[Universal property of disjoint union topology] \label{proposition:universal_property_of_disjoint_union_topology}

    Let $\{X_i\}_{i \in I}$ be a family of topological spaces and let $\coprod_{i \in I} X_i$ be their disjoint union with the disjoint union topology. Then for any topological space $Y$, a function $f : \coprod_{i \in I} X_i \to Y$ is continuous if and only if each composite $f \circ \iota_j : X_j \to Y$ is continuous for all $j \in I$, where $\iota_j : X_j \hookrightarrow \coprod_{i \in I} X_i$ denotes the canonical injection.

    Equivalently, a function $f : Y \to \coprod_{i \in I} X_i$ is continuous if and only if each component map $p_j \circ f : Y \to X_j$ is continuous for all $j \in I$, where $p_j$ denotes the projection onto the $j$-th coordinate (defined on the image of $\iota_j$).
\end{proposition}
