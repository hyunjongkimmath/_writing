\begin{lemma}[Normal Extension via Embeddings] \label{lemma:normal_field_extension_characterization_via_embeddings_into_algebraic_closure}
Let $L/K$ be a \CrefAndHyperrefIfExist{definition:finite_field_extension}{finite extension} and let $\overline{K}$ be an \CrefAndHyperrefIfExist{definition:algebraic_closure_of_a_field}{algebraic closure} of $K$. Then $L/K$ is a \CrefAndHyperrefIfExist{definition:splitting_field_of_polynomials_over_a_field_normal_field_extension}{normal extension} if and only if every \CrefAndHyperrefIfExist{definition:field_homomorphism}{$K$-embedding} $\sigma \colon L \to \overline{K}$ satisfies $\sigma(L) = L$.
\end{lemma}
