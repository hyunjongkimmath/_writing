\begin{proposition}[Heine--Borel theorem for closed and bounded intervals in $\mathbb{R}$] \label{proposition:heine_borel_theorem_for_closed_and_bounded_intervals_in_real_numbers}
    Let $[a,b] \subseteq \mathbb{R}$\CrefIfExists{definition:field_of_real_numbers} be a \CrefAndHyperrefIfExist{definition:interval_in_the_real_line}{closed bounded interval} with $a < b$, equipped with the \CrefAndHyperrefIfExist{definition:subspace_of_a_topological_space}{subspace topology} induced from $\mathbb{R}$. Then $[a,b]$ is \CrefAndHyperrefIfExist{definition:compact_topological_space}{compact}. In other words, every \CrefAndHyperrefIfExist{definition:open_covering_of_a_topological_space}{open cover} of $[a,b]$ admits a finite subcover.
\end{proposition}

\begin{proof}
    Let $\{U_i\}_{i \in I}$ be a collection of open subsets of $\mathbb{R}$ (in the \CrefAndHyperrefIfExist{definition:standard_absolute_value_on_real_numbers_standard_topology_on_real_numbers}{standard topology}) such that $[a,b] \subseteq \bigcup_{i \in I} U_i$. Define
    $$S = \{\, x \in [a,b] : \text{the interval } [a,x] \text{ is covered by finitely many } U_i \,\}.$$
    \CrefIfExists{definition:open_covering_of_a_topological_space}

    The set $S$ is nonempty because $a \in U_{i_0}$ for some $i_0 \in I$, so $[a,a] = \{a\}$ is covered by the single set $U_{i_0}$; consequently $a \in S$.

    Since $S \subseteq [a,b]$, the set $S$ is bounded above (by $b$). By the \CrefAndHyperrefIfExist{definition:least_upper_bound_greatest_lower_bound_property_of_ordered_sets}{least upper bound property} of $\mathbb{R}$\CrefIfExists{proposition:the_field_of_real_numbers_has_the_least_upper_bound_property_and_hence_is_dedekind_complete} the value
    $$c = \sup_{x \in S} x$$
    \CrefIfExists{definition:supremum_infimum_of_a_subset_of_an_ordered_set}
    is a well defined value in $\bbR$. We claim that $c = b$.

    First, $c > a$. Indeed, since $a \in U_{i_0}$ and $U_{i_0}$ is open, there exists $\varepsilon > 0$ such that $(a - \varepsilon, a + \varepsilon) \subseteq U_{i_0}$. Consequently $[a, a + \varepsilon/2] \subseteq U_{i_0}$, so $a + \varepsilon/2 \in S$, whence $c \ge a + \varepsilon/2 > a$.

    Now $c \in [a,b]$ because $c = \sup S \le b$ and $c > a$. Choose $i_c \in I$ with $c \in U_{i_c}$, and pick $\delta > 0$ such that $(c - \delta, c + \delta) \subseteq U_{i_c}$; such a $\delta$ exists because $U_{i_c}$ is open. Suppose, for contradiction, that $c < b$; shrink $\delta$ if necessary so that $c + \delta < b$ as well.

    Since $c = \sup S$, there exists $x \in S$ with $c - \delta < x \le c$. By definition of $S$, the interval $[a,x]$ is covered by finitely many sets from the cover; say $\{U_{i_1}, \dots, U_{i_n}\}$. Then
    $$[a, c + \delta/2] \subseteq [a,x] \cup (c - \delta, c + \delta) \subseteq \bigcup_{j=1}^n U_{i_j} \cup U_{i_c}.$$
    Hence $c + \delta/2 \in S$, contradicting that $c = \sup S$, as $c + \delta/2 > c$. Therefore $c = b$.

    Since $b = c \in [a,b]$, choose $i_b \in I$ with $b \in U_{i_b}$, and pick $\eta > 0$ such that $(b - \eta, b + \eta) \subseteq U_{i_b}$. Because $b = \sup S$, there exists $y \in S$ with $b - \eta < y \le b$. The finite subcover of $[a,y]$ together with $U_{i_b}$ provides a finite subcover of $[a,b]$. Thus $b \in S$ and $[a,b]$ is compact.
\end{proof}
