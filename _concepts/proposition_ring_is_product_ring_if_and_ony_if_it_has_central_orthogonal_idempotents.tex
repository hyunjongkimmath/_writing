\begin{proposition} \label{proposition:ring_is_product_ring_if_and_ony_if_it_has_central_orthogonal_idempotents}
    A \CrefAndHyperrefIfExist{definition:ring}{ring} $R$ is isomorphic to a \CrefAndHyperrefIfExist{definition:products_of_rings}{product ring} $\prod_i R_i$ if and only if $R$ has a \CrefAndHyperrefIfExist{definition:complete_orthogonal_idempotents_of_a_ring}{complete set of} \CrefAndHyperrefIfExist{definition:center_of_a_ring}{central} \CrefAndHyperrefIfExist{definition:orthogonal_idempotents_of_a_ring}{orthogonal idempotents}. More specifically, given a complete set $\{e_1,\ldots,e_n\}$ of orthogonal idempotents of $R$, we have
    $$R \cong \prod_i (e_i) R,$$
    where $(e_i) R$ is the ideal of $R$ generated by $(e_i)$ which is in fact a \CrefAndHyperrefIfExist{definition:ring}{ring} (albeit not a \CrefAndHyperrefIfExist{definition:subring_of_a_ring}{subring} of $R$), and given a decomposition
    $$R \cong \prod_{i=1}^n R_i,$$
    the set of elements $(e_1,0,\ldots,0), (0,e_2,\ldots,0), \ldots, (0,\ldots,e_n)$ is a complete set of orthogonal idempotents.
\end{proposition}

\begin{proof}
    Suppose that $R \cong \prod_{i=1}^n R_i$ for rings $R_1,\ldots,R_n$. Let $\psi: R \to \prod_{i=1}^n R_i$ be a ring isomorphism. For each $i$, let $e'_i \in \prod_{j=1}^n R_j$ be the element with $1_{R_i}$ in the $i$-th coordinate and $0$ in all other coordinates. Set $e_i = \psi^{-1}(e'_i)$. Since each $e'_i$ is idempotent, orthogonal to $e'_j$ for $j \neq i$, central, and $\sum e'_i = (1_{R_1},\ldots,1_{R_n}) = 1_{\prod R_j}$, the same properties hold for $e_i$ in $R$. Hence $\{e_1,\ldots,e_n\}$ is a complete set of \CrefAndHyperrefIfExist{definition:center_of_a_ring}{central} orthogonal idempotents.

    Conversely, suppose that $\{e_1,\ldots,e_n\}$ is a complete set of \CrefAndHyperrefIfExist{definition:complete_orthogonal_idempotents_of_a_ring}{orthogonal idempotents} in $R$, with each $e_i$ lying in the \CrefAndHyperrefIfExist{definition:center_of_a_ring}{center} of $R$. For each $i$, let $R_i = e_i R = \{e_i r : r \in R\}$. Since $e_i$ is central and idempotent, $R_i$ is a ring with multiplicative identity $e_i$.

    Define
    $$\Phi: R \longrightarrow \prod_{i=1}^n R_i, \quad r \longmapsto (e_1 r, e_2 r, \ldots, e_n r).$$

    We first show that $\Phi$ is a ring homomorphism. For $r,s \in R$:
    $$\Phi(r+s) = (e_1(r+s),\ldots,e_n(r+s)) = (e_1 r + e_1 s,\ldots,e_n r + e_n s) = \Phi(r) + \Phi(s).$$
    For multiplication, using centrality of $e_i$:
    $$\Phi(rs) = (e_1 rs,\ldots,e_n rs) = (e_i^2 rs)_i = (e_i r e_i s)_i = (e_i r \cdot e_i s)_i = \Phi(r)\Phi(s).$$
    Also $\Phi(1_R) = (e_1,\ldots,e_n) = (1_{R_1},\ldots,1_{R_n})$.

    Next we show that $\Phi$ is \CrefAndHyperrefIfExist{definition:injective_and_projective_objects_in_a_category}{injective}. Suppose that $\Phi(r) = (0,\ldots,0)$. Then $e_i r = 0$ for all $i$. Since $\sum_{i=1}^n e_i = 1_R$, we have
    $$r = 1_R \cdot r = \left(\sum_{i=1}^n e_i\right)r = \sum_{i=1}^n e_i r = 0.$$

    Therefore, $\Phi$ has trivial kernel, so $\Phi$ is injective\CrefIfExists{proposition:ring_homomorphism_is_injective_iff_kernel_is_trivial}.
    

    Finally we show that $\Phi$ is \CrefAndHyperrefIfExist{definition:property_of_representable_1_morphism_of_categories_fibered_in_groupoids_over_asite_on_the_category_of_schemes_over_a_scheme}{surjective}. Let $(x_1,\ldots,x_n) \in \prod_{i=1}^n R_i$. For each $i$, write $x_i = e_i r_i$ for some $r_i \in R$. Set $r = \sum_{j=1}^n e_j r_j$. Then for any $k$:
    $$e_k r = e_k \sum_{j=1}^n e_j r_j = \sum_{j=1}^n e_k e_j r_j.$$
    By orthogonality, $e_k e_j = 0$ when $j \neq k$, and $e_k e_k = e_k^2 = e_k$. Hence
    $$e_k r = e_k r_k = x_k.$$
    Thus $\Phi(r) = (x_1,\ldots,x_n)$, so $\Phi$ is surjective.

    In conclusion, $\Phi$ is a ring isomorphism $R \cong \prod_{i=1}^n R_i$.
\end{proof}
