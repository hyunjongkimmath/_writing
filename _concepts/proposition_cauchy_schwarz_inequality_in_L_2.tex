\begin{proposition}[Cauchy--Schwarz inequality] \label{proposition:cauchy_schwarz_inequality_in_L_2}
Let $(X, \mathcal{M}, \mu)$ be a \CrefAndHyperrefIfExist{definition:measure_on_a_measurable_space_valued_in_the_extended_real_line_and_measure_space}{measure space}. For any measurable functions $f, g : X \to \mathbb{C}$ such that $f, g \in L^2(\mu)$,
$$\left|\int_X f \overline{g} \, d\mu\right| \leq \|f\|_2 \cdot \|g\|_2 = \left(\int_X |f|^2 \, d\mu\right)^{1/2} \left(\int_X |g|^2 \, d\mu\right)^{1/2},$$
where $\|\cdot\|_2$ is the \CrefAndHyperrefIfExist{definition:L_p_norm_on_a_measure_space}{$L^2$-norm}. In particular, if $(\Omega, \mathcal{F}, P)$ is a \CrefAndHyperrefIfExist{definition:probability_space}{probability space} and $X, Y$ are random variables with $\mathbb{E}[X^2] < \infty$ and $\mathbb{E}[Y^2] < \infty$, then
$$|\mathbb{E}[XY]| \leq (\mathbb{E}[X^2])^{1/2} (\mathbb{E}[Y^2])^{1/2},$$
with equality if and only if $X$ and $Y$ are linearly dependent almost surely. This is the special case of \CrefAndHyperrefIfExist{proposition:holders_inequality}{Hölder's inequality} for conjugate exponents $p = q = 2$.
\end{proposition}
