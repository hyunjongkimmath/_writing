\begin{proposition}[Distance function to a fixed point in an extended metric space is continuous]

Let $T$ be a commutative \CrefAndHyperrefIfExist{definition:ordered_semiring}{ordered semiring}, let $T^\infty$ be the \CrefAndHyperrefIfExist{definition:ordered_semiring_with_adjoined_infinity}{ordered semiring with adjoined infinity} obtained from $T$, and let $(X, d)$ be an extended metric space valued in $T^\infty$\CrefIfExists{definition:extended_metric_on_a_set_valued_in_an_ordered_commutative_monoid_with_adjoined_infinity}.

Fix a point $p \in X$. The distance function to $p$,
$$\delta_p : X \to T^\infty, \quad x \mapsto d(x, p),$$
is continuous on $\{x \in X : d(x, p) < \infty\}$ with respect to the topology induced by $d$. In particular, for all $x, y$ in this set,
$$|d(x, p) - d(y, p)| \leq d(x, y),$$
so $\delta_p$ is Lipschitz continuous with Lipschitz constant $1$\CrefIfExists{proposition:reverse_triangle_inequality_in_extended_metric_space}.
\end{proposition}
