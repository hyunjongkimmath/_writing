\begin{proposition}[$\sigma$-complete lattice-ordered semimodule with total order coincides with conditionally $\sigma$-complete linear order] \label{proposition:sigma_complete_lattice_ordered_semimodule_with_total_order_coincides_with_conditionally_sigma_complete_linear_order}

Let $K$ be an \CrefAndHyperrefIfExist{definition:ordered_semiring}{ordered semiring}, and let $M$ be a \CrefAndHyperrefIfExist{definition:lattice_ordered_semimodule_over_an_ordered_semiring}{lattice-ordered semimodule} over $K$ whose partial order $\leq$ is a \CrefAndHyperrefIfExist{definition:total_order_linear_order_on_a_set}{total order}.

Then $M$ is a \hldef{$\sigma$-complete lattice-ordered semimodule}\CrefIfExists{definition:sigma_complete_lattice_ordered_semimodule_over_an_ordered_semiring} if and only if $(M, \leq)$ is a \CrefAndHyperrefIfExist{definition:conditionally_sigma_complete_linear_order}{conditionally $\sigma$-complete linear order}.

In one direction, a conditionally $\sigma$-complete linear order requires every non-empty countable subset bounded above to have a supremum — this is precisely the defining property of a $\sigma$-complete lattice-ordered semimodule when the order is total. In the other direction, the $\sigma$-completeness of $M$ as a lattice-ordered semimodule guarantees that every non-empty countable subset bounded above has a supremum and every non-empty countable subset bounded below has an infimum (by duality), which are exactly the requirements for conditional $\sigma$-completeness.
\end{proposition}
