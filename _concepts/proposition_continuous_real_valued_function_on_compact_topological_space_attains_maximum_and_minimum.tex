\begin{proposition}[Continuous real-valued function on a compact topological space attains maximum and minimum] \label{proposition:continuous_real_valued_function_on_compact_topological_space_attains_maximum_and_minimum}
    \TODO{AI generated, verify}
    Let $X$ be a \CrefAndHyperrefIfExist{definition:compact_topological_space}{compact topological space} and let $f : X \to \mathbb{R}$ be a \CrefAndHyperrefIfExist{definition:continuous_map_of_topological_spaces}{continuous function}. Then $f$ is bounded above and below, and attains its maximum and minimum, i.e.\ there exist $x_{\max}, x_{\min} \in X$ such that
    $$f(x_{\max}) = \sup_{x \in X} f(x), \qquad f(x_{\min}) = \inf_{x \in X} f(x).$$
\end{proposition}

\begin{proof}

    We prove the statement for the maximum; the minimum follows by applying the same argument to $-f$.

    Let $M = \sup_{x \in X} f(x) \in \mathbb{R} \cup \{+\infty\}$. We first show that $M < \infty$, i.e.\ $f$ is bounded above. For each $n \in \mathbb{N}$, consider the open set
    $$U_n = \{x \in X : f(x) < n\}.$$
    Since $f$ is continuous, each $U_n$ is open. The collection $\{U_n\}_{n=1}^\infty$ forms an open cover of $X$ because for each $x \in X$, $f(x) < n$ for sufficiently large $n$. By compactness of $X$, there exists a finite subcover $U_{n_1}, \dots, U_{n_k}$. Let $N = \max\{n_1, \dots, n_k\}$. Then $X = U_N$, so $f(x) < N$ for all $x \in X$, implying $M \le N < \infty$.

    Now we show that $M$ is attained. Suppose for contradiction that $f(x) < M$ for all $x \in X$. For each $x \in X$, let $\varepsilon_x = M - f(x) > 0$, and consider the open set
    $$V_x = \{y \in X : f(y) < f(x) + \varepsilon_x\} = \{y \in X : f(y) < M - \varepsilon_x + \varepsilon_x\} = \{y \in X : f(y) < M\} = X,$$
    which is not helpful. Instead, consider the open sets
    $$W_x = \{y \in X : f(y) < f(x) + \varepsilon_x/2\} = \{y \in X : f(y) < (M + f(x))/2\}.$$
    Each $W_x$ is open by continuity of $f$, and $x \in W_x$, so $\{W_x\}_{x \in X}$ is an open cover of $X$. By compactness, there exists a finite subcover $W_{x_1}, \dots, W_{x_m}$. Let $\delta = \max_{i=1,\dots,m} (M - f(x_i))$ and note that $0 < \delta < M$ because each $f(x_i) < M$. For any $y \in X$, we have $y \in W_{x_i}$ for some $i$, so $f(y) < (M + f(x_i))/2 = M - (M - f(x_i))/2 \le M - \delta/2$. Hence $\sup_{x \in X} f(x) \le M - \delta/2 < M$, contradicting the definition of $M$ as the supremum. Therefore $M$ is attained.
\end{proof}
