\begin{theorem}[Radon--Nikodym] \label{theorem:radon_nikodym_theorem}
Let $(X, \mathcal{A}, \mu)$ be a \CrefAndHyperrefIfExist{definition:measure_on_a_measurable_space_and_measure_space}{measure space} with $\mu$ \CrefAndHyperrefIfExist{definition:finite_sigma_finite_measure_space_for_a_measure_on_a_measurable_space}{$\sigma$-finite}, and let $\nu : \mathcal{A} \to [0, \infty]$ be another measure such that $\nu \ll \mu$ (i.e., $\nu$ is \CrefAndHyperrefIfExist{definition:absolutely_continuous_and_singular_measures_for_a_measure_on_a_measurable_space}{absolutely continuous with respect to $\mu$}).

Then there exists a nonnegative \CrefAndHyperrefIfExist{definition:measurable_function_between_measure_spaces}{measurable function} $f : X \to [0, \infty)$ such that for every $A \in \mathcal{A}$,
$$\nu(A) = \int_A f\,d\mu.$$
Moreover, $f$ is unique up to \CrefAndHyperrefIfExist{definition:property_holds_almost_everywhere_for_a_measure_space}{$\mu$-almost everywhere} equality: if $g : X \to [0, \infty)$ is another measurable function satisfying $\nu(A) = \int_A g\,d\mu$ for all $A \in \mathcal{A}$, then $f = g$ $\mu$-a.e.

The function $f$ is called the \hldef{Radon--Nikodym derivative of $\nu$ with respect to $\mu$}, denoted \hl{$\frac{d\nu}{d\mu}$}.
\end{theorem}
