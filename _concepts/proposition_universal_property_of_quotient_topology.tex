\begin{proposition}[Universal property of quotient topology] \label{proposition:universal_property_of_quotient_topology}

    Let $X$ be a topological space and let $\sim$ be an equivalence relation on the underlying set. Write $\pi : X \to X/\sim$ for the canonical quotient map, where $X/\sim$ carries the quotient topology. Then for any topological space $Y$, a function $f : X/\sim \to Y$ is continuous if and only if the composition $f \circ \pi : X \to Y$ is continuous.

    More generally, let $X$ be a topological space, $Y$ a set, and $f : X \to Y$ any surjective map. Endow $Y$ with the quotient topology induced by $f$. Then for any topological space $Z$, a function $g : Y \to Z$ is continuous if and only if $g \circ f : X \to Z$ is continuous.
\end{proposition}
