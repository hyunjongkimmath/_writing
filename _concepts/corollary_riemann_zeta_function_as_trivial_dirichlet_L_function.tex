The \CrefAndHyperrefIfExist{definition:riemann_zeta_function}{Riemann zeta function} $\zeta(s)$ coincides with the Dirichlet $L$-function of the trivial Dirichlet character modulo $1$ (or modulo $0$ in the classical convention):
\[
\zeta(s) = L(s, \mathbf{1}_1).

Here $\mathbf{1}_1$ denotes the unique Dirichlet character modulo $1$ defined by $\mathbf{1}_1(n) = 1$ for all $n \in \mathbb{Z}$.
