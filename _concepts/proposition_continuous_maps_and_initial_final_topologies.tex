\begin{proposition}[Universal property of initial and final topologies] \label{proposition:continuous_maps_and_initial_final_topologies}

    Let $S$ be a set, $\{X_i\}_{i \in I}$ a family of topological spaces, and $\{f_i : S \to X_i\}_{i \in I}$ a family of functions. If $S$ is equipped with the initial topology with respect to this family, then for any topological space $Y$, a function $g : Y \to S$ is continuous if and only if each composite $f_i \circ g : Y \to X_i$ is continuous for all $i \in I$.

    Dually, let $X$ be a topological space and $\{f_i : X_i \to X\}_{i \in I}$ a family of functions. If $X$ carries the final topology with respect to this family, then for any topological space $Y$, a function $g : X \to Y$ is continuous if and only if each composite $g \circ f_i : X_i \to Y$ is continuous for all $i \in I$.
\end{proposition}
