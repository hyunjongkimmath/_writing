For all integers $k \geq 2$, the following trivial Ramsey numbers hold:
$$R(1,k) = 1, \quad R(2,k) = k, \quad R(k,2) = k.$$

The equality $R(2,k) = k$ follows because any graph on $k$ vertices either contains an edge (a clique of size 2) or is empty (an independent set of size $k$). The symmetry $R(r,s) = R(s,r)$ will be established in \CrefAndHyperrefIfExist{proposition:symmetry_of_two_color_ramsey_numbers_R_r_s_equals_R_s_r}{the next proposition}.
\end{proposition}
