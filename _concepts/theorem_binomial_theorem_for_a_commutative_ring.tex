\begin{theorem}[Binomial theorem] \label{theorem:binomial_theorem_for_a_commutative_ring}
    Let $R$ be a \CrefAndHyperrefIfExist{definition:commutative_ring}{commutative ring}, and let $a, b \in R$. For each nonnegative integer $n \in \mathbb{Z}_{\geq 0}$, we have
    $$\hlin{(a + b)^n = \sum_{k=0}^n \binom{n}{k} a^k b^{n-k}}$$
    where $\binom{n}{k}$ is the \CrefAndHyperrefIfExist{definition:combinatorial_choose_function_binomial_coefficient}{binomial coefficient}, and $a^k$, $b^{n-k}$ are the \CrefAndHyperrefIfExist{definition:exponentiation_in_a_semiring}{$k$th and $(n-k)$th powers} in the multiplicative monoid of $R$.
\end{theorem}

\begin{proof}
    We proceed by \CrefAndHyperrefIfExist{proposition:mathematical_induction_on_natural_numbers}{induction} on $n$.

    For the base case $n = 0$, we have $(a + b)^0 = 1_R$ and $\binom{0}{0} a^0 b^0 = 1 \cdot 1_R \cdot 1_R = 1_R$, so the formula holds.

    Inductively assume that the formula holds for some $n \geq 0$. We prove it for $n + 1$. Compute:
    $$\begin{aligned}
        (a + b)^{n+1} &= (a + b) \sum_{k=0}^n \binom{n}{k} a^k b^{n-k} \\
        &= \sum_{k=0}^n \binom{n}{k} a^{k+1} b^{n-k} + \sum_{k=0}^n \binom{n}{k} a^k b^{n+1-k}.
    \end{aligned}$$
    In the first sum, shift the index by setting $j = k + 1$, so that it becomes $\sum_{j=1}^{n+1} \binom{n}{j-1} a^j b^{n+1-j}$. The second sum can be rewritten with the same index as $\sum_{j=0}^{n+1} \binom{n}{j} a^j b^{n+1-j}$. Combining, we obtain:
    $$\begin{aligned}
        (a + b)^{n+1} &= \binom{n}{0} a^0 b^{n+1} + \sum_{j=1}^n \left( \binom{n}{j-1} + \binom{n}{j} \right) a^j b^{n+1-j} + \binom{n}{n} a^{n+1} b^0.
    \end{aligned}$$
    The coefficient of $a^j b^{n+1-j}$ for $1 \leq j \leq n$ is $\binom{n}{j-1} + \binom{n}{j}$. By \Cref{lemma:pascal_identity_for_binomial_coefficients}, this equals $\binom{n+1}{j}$. The boundary terms satisfy $\binom{n}{0} = 1 = \binom{n+1}{0}$ and $\binom{n}{n} = 1 = \binom{n+1}{n+1}$. Therefore:
    $$(a + b)^{n+1} = \sum_{j=0}^{n+1} \binom{n+1}{j} a^j b^{n+1-j},$$
    completing the induction.
\end{proof}
