\begin{proposition} \label{proposition:function_of_topological_spaces_is_continuous_if_and_only_if_subbasis_members_are_pulled_back_to_open_sets}
Let $X$ and $Y$ be \CrefAndHyperrefIfExist{definition:topological_space}{topological spaces}, and let $\mathcal{S}$ be a \CrefAndHyperrefIfExist{definition:topology_on_a_set_generated_by_a_collection_of_subsets_and_subbasis_for_a_topology}{subbasis} for the \CrefAndHyperrefIfExist{definition:topological_space}{topology} on $Y$. 
A \CrefAndHyperrefIfExist{definition:function_of_sets}{function} $f: X \to Y$ is \CrefAndHyperrefIfExist{definition:continuous_map_of_topological_spaces}{continuous} if and only if $f^{-1}(V)$ is an \CrefAndHyperrefIfExist{definition:topological_space}{open} set in $X$ for every $V \in \mathcal{S}$.
\end{proposition}
