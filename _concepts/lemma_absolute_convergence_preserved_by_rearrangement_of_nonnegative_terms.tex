\begin{lemma}[Rearrangement preserves convergence of series of nonnegative elements in a totally ordered abelian group with the least upper bound property] \label{lemma:absolute_convergence_preserved_by_rearrangement_of_nonnegative_terms}

    Let $G$ be a \CrefAndHyperrefIfExist{definition:ordered_abelian_group}{totally ordered abelian group} with the \CrefAndHyperrefIfExist{definition:least_upper_bound_greatest_lower_bound_property_of_ordered_sets}{least upper bound property}. Let $(a_n)_{n=1}^\infty$ be a sequence in $G$\CrefIfExists{definition:monotone_sequence_of_elements_in_a_partially_ordered_set} with $a_n \geq 0$ for all $n$. Let $\sigma : \mathbb{N} \to \mathbb{N}$ be any bijection. 
    
    % For a series of nonnegative terms, we say that it \hldef{converges} if its sequence of partial sums is bounded above; in this case the supremum of the partial sums exists by the least upper bound property, and the series is said to \hldef{converge to} that supremum.

    Then $\sum_{n=1}^\infty a_n$ \CrefAndHyperrefIfExist{definition:infinite_series_and_convergence_of_infinite_series_in_a_topological_abelian_semigroup}{converges} if and only if $\sum_{n=1}^\infty a_{\sigma(n)}$ converges, and in that case
    $$\sum_{n=1}^\infty a_{\sigma(n)} = \sum_{n=1}^\infty a_n.$$
\end{lemma}

\begin{proof}
    Let $S_N = \sum_{n=1}^N a_n$ and $T_M = \sum_{m=1}^M a_{\sigma(m)}$ denote the partial sums of the original and rearranged series respectively. Since $a_n \geq 0$ for all $n$, both $(S_N)$ and $(T_M)$ are \CrefAndHyperrefIfExist{definition:monotone_sequence_of_elements_in_a_partially_ordered_set}{nondecreasing} sequences.

    We first show that if $\sum a_n$ converges, then $\sum a_{\sigma(n)}$ also converges and has the same sum. Let $S = \sup\{S_N : N \in \mathbb{N}\}$ be the sum of the original series\TODO{reference the monotone convergence theorem in this generality}.

    For any $M \in \mathbb{N}$, let $K = \max\{\sigma(1), \sigma(2), \dots, \sigma(M)\}$. Then $\{\sigma(1), \dots, \sigma(M)\} \subseteq \{1, \dots, K\}$, so since all terms are nonnegative we have
    $$T_M = \sum_{m=1}^M a_{\sigma(m)} \leq \sum_{n=1}^K a_n = S_K \leq S.$$
    Hence $(T_M)$ is bounded above by $S$, so $\sum a_{\sigma(n)}$ converges, and its sum $T := \sup\{T_M : M \in \mathbb{N}\}$ satisfies $T \leq S$.

    % By symmetry, $S \leq T$ as well --- since $\sigma$ is a bijection, 

    Conversely, for any $N \in \mathbb{N}$, since $\sigma$ is surjective, there exists for each $n \in \{1, \dots, N\}$ some $m_n$ such that $\sigma(m_n) = n$. Let $M = \max\{m_1, \dots, m_N\}$. Then $\{1, \dots, N\} \subseteq \{\sigma(1), \dots, \sigma(M)\}$, so
    $$S_N \leq \sum_{m=1}^M a_{\sigma(m)} = T_M \leq T.$$
    Thus $S = \sup\{S_N : N \in \mathbb{N}\} \leq T$. Combining $T \leq S$ and $S \leq T$, we obtain $S = T$.

    The reverse direction follows by applying the same argument to the bijection $\sigma^{-1}$: if $\sum a_{\sigma(n)}$ converges to $S'$, then rearranging back via $\sigma^{-1}$ gives $\sum a_n = S'$.
\end{proof}
