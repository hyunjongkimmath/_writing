\begin{theorem}[Arzelà–Ascoli theorem] \label{theorem:arzela_ascoli_theorem}

    Let $K$ be a \CrefAndHyperrefIfExist{definition:compact_topological_space}{compact} \CrefAndHyperrefIfExist{definition:extended_metric_on_a_set_valued_in_an_ordered_semiring_with_adjoined_infinity}{metric space} and let $C(K)$ denote the space of \CrefAndHyperrefIfExist{definition:continuous_map_of_topological_spaces}{continuous} functions $f : K \to \mathbb{R}$ (or $\mathbb{C}$) equipped with the \CrefAndHyperrefIfExist{definition:uniform_convergence_of_a_sequence_of_functions_from_a_set_to_an_extended_metric_space}{uniform norm}. A subset $\mathcal{F} \subseteq C(K)$ is \hldef{compact} in the uniform topology if and only if it is closed, pointwise bounded, and \CrefAndHyperrefIfExist{definition:equicontinuous_family_of_functions_between_metric_spaces}{equicontinuous}.

    Equivalently, every sequence in a pointwise bounded and equicontinuous family of continuous functions on $K$ admits a subsequence that converges uniformly on $K$ to a continuous function.
\end{theorem}

\begin{proof}
    \TODO{AI generated, verify}
We equip $C(K)$ with the uniform metric $$d_\infty(f,g) = \sup_{x \in K} |f(x) - g(x)|,$$ which is well-defined since $K$ is compact and each continuous function on a compact space is bounded. By \CrefAndHyperrefIfExist{definition:uniform_convergence_of_a_sequence_of_functions_from_a_set_to_an_extended_metric_space}, $(C(K), d_\infty)$ is an extended metric space, so a subset is compact if and only if it is complete and totally bounded.

We prove both directions using this characterization.

\begin{enumerate}
    \item First we assume that $\mathcal{F}$ is compact in $C(K)$ and show that it must be closed, pointwise bounded, and equicontinuous. Since an extended metric space is Hausdorff (by the separation properties of \CrefAndHyperrefIfExist{definition:extended_metric_space}), every compact subset is closed, so $\mathcal{F}$ is closed in $C(K)$.

    For each $x \in K$, consider the evaluation map $\operatorname{ev}_x : C(K) \to \mathbb{R}$ defined by $\operatorname{ev}_x(f) = f(x)$. From the definition of the uniform metric, for any $f,g \in C(K)$ we have $$|f(x) - g(x)| \leq d_\infty(f,g),$$ so $\operatorname{ev}_x$ is Lipschitz with constant $1$ in the sense of \CrefAndHyperrefIfExist{definition:lipschitz_continuous_function_between_metric_spaces}, and hence continuous. The image of a compact set under a continuous map is compact, so for each fixed $x$, the set $\operatorname{ev}_x(\mathcal{F}) = \{f(x) : f \in \mathcal{F}\}$ is a compact subset of $\mathbb{R}$. This means it is closed and bounded in $\mathbb{R}$, so its closure is compact. Thus $\mathcal{F}$ is pointwise bounded.

    To prove equicontinuity at each $x_0 \in K$, let $\varepsilon > 0$ be given. Since $\mathcal{F}$ is compact in $(C(K), d_\infty)$, it can be covered by finitely many open balls of radius $\varepsilon/3$: $$\mathcal{F} \subseteq \bigcup_{i=1}^N B_\infty(f_i, \varepsilon/3)$$ for some $f_1, \dots, f_N \in C(K)$, where $B_\infty(f_i, \varepsilon/3) = \{g \in C(K) : d_\infty(g,f_i) < \varepsilon/3\}$. Each $f_i$ is continuous at $x_0$, so for each $i$ there exists an open neighborhood $U_i$ of $x_0$ such that $$|f_i(x) - f_i(x_0)| < \varepsilon/3$$ for all $x \in U_i$. Let $U = \bigcap_{i=1}^N U_i$, which is a finite intersection and hence an open neighborhood of $x_0$. For any $f \in \mathcal{F}$, there exists some index $j$ such that $d_\infty(f,f_j) < \varepsilon/3$. Then for all $x \in U$, the triangle inequality gives $$|f(x) - f(x_0)| \leq |f(x) - f_j(x)| + |f_j(x) - f_j(x_0)| + |f_j(x_0) - f(x_0)| < \varepsilon/3 + \varepsilon/3 + \varepsilon/3 = \varepsilon.$$ Since this bound holds uniformly for all $f \in \mathcal{F}$, the family $\mathcal{F}$ is equicontinuous at $x_0$.

    \item Now we assume that $\mathcal{F}$ is closed, pointwise bounded, and equicontinuous, and show that it is compact by proving completeness and total boundedness.

    To prove completeness, let $(f_n)$ be a Cauchy sequence in $\mathcal{F}$ with respect to $d_\infty$. For each fixed $x \in K$, the sequence $(f_n(x))$ is Cauchy in $\mathbb{R}$ because $$|f_n(x) - f_m(x)| \leq d_\infty(f_n,f_m).$$ Since $\mathbb{R}$ is complete and each set $\overline{\{f(x) : f \in \mathcal{F}\}}$ is compact (hence complete as a closed subset of $\mathbb{R}$), the sequence $(f_n(x))$ converges to some limit; call it $f(x)$. This defines a function $f: K \to \mathbb{R}$.

    We claim that $f_n \to f$ uniformly. Given $\varepsilon > 0$, choose $N$ such that $d_\infty(f_n, f_m) < \varepsilon/2$ for all $n,m \geq N$. For each fixed $x \in K$, we have $$|f_N(x) - f(x)| = \lim_{m \to \infty} |f_N(x) - f_m(x)| \leq \varepsilon/2,$$ so $\sup_{x \in K} |f_N(x) - f(x)| \leq \varepsilon/2 < \varepsilon$. Hence $d_\infty(f_N, f) < \varepsilon$, which means $f_n \to f$ uniformly. Since each $f_n$ is continuous and the uniform limit of continuous functions is continuous (by \CrefAndHyperrefIfExist{definition:uniform_convergence_of_a_sequence_of_functions_from_a_set_to_an_extended_metric_space}), we have $f \in C(K)$. Because $\mathcal{F}$ is closed in $C(K)$, it follows that $f \in \mathcal{F}$. Thus every Cauchy sequence in $\mathcal{F}$ converges to an element of $\mathcal{F}$, so $\mathcal{F}$ is complete.

    To prove total boundedness, let $\varepsilon > 0$ be given. By equicontinuity at each point $x \in K$, for every $x$ there exists an open neighborhood $U_x$ of $x$ such that $$|f(x) - f(y)| < \varepsilon/3$$ for all $y \in U_x$ and all $f \in \mathcal{F}$. The collection $\{U_x : x \in K\}$ is an open cover of the compact space $K$, so there exists a finite subcover $\{U_{x_1}, \dots, U_{x_N}\}$ for some points $x_1, \dots, x_N \in K$.

    Consider the evaluation map $$E : C(K) \to \mathbb{R}^N, \quad E(h) = \bigl(h(x_1), h(x_2), \dots, h(x_N)\bigr).$$ The image $E(\mathcal{F})$ is a subset of $\mathbb{R}^N$, and each coordinate set $\{h(x_i) : h \in \mathcal{F}\}$ has compact closure in $\mathbb{R}$ by pointwise boundedness. Therefore, by the Heine–Borel theorem (a subset of $\mathbb{R}^N$ is compact if and only if it is closed and bounded), the set $E(\mathcal{F})$ is relatively compact in $\mathbb{R}^N$, which means its closure $\overline{E(\mathcal{F})}$ is compact. Since a compact subset of any metric space is totally bounded, we can cover $\overline{E(\mathcal{F})}$ by finitely many open balls of radius $\varepsilon/3$ in the sup-norm on $\mathbb{R}^N$. Hence there exist functions $h_1, \dots, h_M \in \mathcal{F}$ such that for any $f \in \mathcal{F}$, there is some index $j$ with $$|f(x_i) - h_j(x_i)| < \varepsilon/3$$ for all $i = 1, \dots, N$.

    Now fix any $f \in \mathcal{F}$ and choose $h_j$ as above. For any point $x \in K$, there exists some index $i$ such that $x \in U_{x_i}$. Then the triangle inequality gives $$|f(x) - h_j(x)| \leq |f(x) - f(x_i)| + |f(x_i) - h_j(x_i)| + |h_j(x_i) - h_j(x)| < \varepsilon/3 + \varepsilon/3 + \varepsilon/3 = \varepsilon,$$ where the first and third terms are bounded by equicontinuity (since both $f, h_j \in \mathcal{F}$) and the middle term is bounded by our choice of $h_j$. Taking the supremum over all $x \in K$, we obtain $$d_\infty(f,h_j) = \sup_{x \in K} |f(x) - h_j(x)| \leq \varepsilon.$$ Thus $\mathcal{F}$ can be covered by finitely many balls of radius $\varepsilon$ in $(C(K), d_\infty)$, proving total boundedness.

    Since $\mathcal{F}$ is both complete and totally bounded in the extended metric space $(C(K), d_\infty)$, it is compact.
\end{enumerate}
This completes the proof of the Arzelà–Ascoli theorem.
\end{proof}
