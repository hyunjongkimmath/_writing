\begin{proposition}[{\cite[See Tags 041K, 041L, 041N, 0410, 041P, 0CFW, 041Q, 041R, 0CFX, 041S, 041T, 041U, 041V, 041W, 041X, 041Y, 041Z, 0410, 0421, 0422, 0423, 0424, 0425, 0426, 0427, 0428, 0429, 042A, 042B, 042C, 042D]{stacks-project}}] \label{proposition:list_of_propeties_of_morphisms_between_algebraic_spaces_that_are_fpqc_local}

    Let $S$ be a \CrefAndHyperrefIfExist{definition:scheme}{scheme}. The following properties of morphisms $f$ between \CrefAndHyperrefIfExist{definition:algebraic_space_on_a_site_on_Sch_S_that_preserves_under_base_change_and_has_tau_local_surjectivity_and_etaleness}{algebraic spaces} (for the \CrefAndHyperrefIfExist{definition:big_fppf_site_of_a_scheme}{big fppf site}) over $S$ are fpqc \CrefAndHyperrefIfExist{definition:tau_local_property_of_a_morphism_of_algebraic_spaces_over_a_scheme}{local on the target} (see \Cref{definition:property_for_a_representable_morphism_of_sheaves_coming_from_a_property_of_morphisms_of_schemes_preserved_by_base_change_and_base_local}, which can be used to define various properties of morphisms between algebraic spaces and \Cref{proposition:list_of_properties_of_morphisms_of_schemes_over_a_base_preserved_under_base_change_and_fpqc_local_on_the_base}, which lists various properties which can be consequently defined for morphisms between algebraic spaces):
    \begin{enumerate}
        \item $f$ is quasi-compact
        \item $f$ is quasi-separated
        \item $f$ is universally closed
        \item $f$ is universally open 
        \item $f$ is universally submersive
        \item $f$ is surjective
        \item $f$ is universally injective
        \item $f$ is a universal homeomorphism
        \item $f$ is locally of finite type
        \item $f$ is locally of finite presentation
        \item $f$ is of finite type
        \item $f$ is of finite presentation
        \item $f$ is flat
        \item $f$ is an open immersoin
        \item $f$ is an isomorphism
        \item $f$ is affine
        \item $f$ is a closed immersion
        \item $f$ is separated
        \item $f$ is proper
        \item $f$ is quasi-affine
        \item $f$ is a quasi-compact immersion
        \item $f$ is integral
        \item $f$ is finite
        \item $f$ is locally quasi-finite
        \item $f$ is syntomic
        \item $f$ is smooth
        \item $f$ is unramified
        \item $f$ is \'etale
        \item $f$ is finite locally free
        \item $f$ is a monomorphism
    \end{enumerate}
\end{proposition}
