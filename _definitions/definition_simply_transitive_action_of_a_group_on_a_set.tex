\begin{definition}[Simply transitive action of a group on a set] \label{definition:simply_transitive_action_of_a_group_on_a_set}
Let $(G,\cdot)$ be a \CrefAndHyperrefIfExist{definition:group}{group} \CrefAndHyperrefIfExist{definition:left_and_right_group_actions_on_a_set}{acting on the left} a set $X$.
The action is called \hldef{simply transitive} (or \hldef{regular}) if it is both \CrefAndHyperrefIfExist{definition:transitive_group_action_of_a_group_acting_on_a_set}{transitive} and \CrefAndHyperrefIfExist{definition:free_action_of_a_group_on_a_set}{free}. Equivalently, for any two elements $x, y \in X$, there exists a unique element $g \in G$ such that
$$g \cdot x = y.$$
\end{definition}
