\begin{definition} \label{definition:group_object_in_an_infty_category}

    Let $\mathcal{C}$ be an \CrefAndHyperrefIfExist{definition:infty_category_quasi_category}{$\infty$-category} admitting a \CrefAndHyperrefIfExist{definition:terminal_object_in_an_infty_category}{terminal object} $*$ and \CrefAndHyperrefIfExist{definition:pullback_and_pushforward_of_maps_to_and_from_objects_in_an_infty_category}{finite pullbacks}.

    A \hldef{group object in $\mathcal{C}$} is a \CrefAndHyperrefIfExist{definition:monoid_object_in_an_infty_category}{monoid object} $M$ in $\mathcal{C}$ (presented by a simplicial object $X : \Delta^{\mathrm{op}} \to \mathcal{C}$ with $X_0 \simeq *$) satisfying either of the following equivalent conditions:
    \begin{enumerate}
        \item For every object $Y \in \mathcal{C}$, the monoid of connected components $\pi_0(\Map_{\mathcal{C}}(Y, M))$ is a \CrefAndHyperrefIfExist{definition:group}{group}.
        \item The shear map $X_2 \to X_1 \times X_1$ induced by the face maps $(d_0, d_2)$ is an equivalence in $\mathcal{C}$.
    \end{enumerate}

    A group object $G$ is called \hldef{abelian} if its underlying monoid structure extends to a commutative monoid object (an algebra over the commutative $\infty$-operad $\mathcal{C}om$). This implies that for every $Y \in \mathcal{C}$, the group $\pi_0(\Map_{\mathcal{C}}(Y, G))$ is abelian.

\end{definition}
