\begin{definition}[Totally Real and Totally Imaginary Number Fields] \label{definition:totally_real_and_totally_imaginary_number_fields}
Let $K$ be a \CrefAndHyperrefIfExist{definition:number_field}{number field} with \CrefAndHyperref{definition:archimedean_invariants_of_a_number_field}{signature} $(r_1, r_2)$.

The number field $K$ is called a \hldef{totally real number field} if $r_2 = 0$, i.e., all \CrefAndHyperrefIfExist{definition:field_homomorphism}{embeddings} of $K$ into $\mathbb{C}$ have image contained in $\mathbb{R}$. Equivalently, every element of $K$ has only real \CrefAndHyperrefIfExist{definition:galois_conjugate_of_element_of_field_extension_in_algebraic_closure}{conjugates}.

The number field $K$ is called a \hldef{totally imaginary number field} if $r_1 = 0$, i.e., no embedding of $K$ into $\mathbb{C}$ has image contained in $\mathbb{R}$. Equivalently, every element of $K$ not lying in a totally real subfield has at least one nonreal conjugate.
\end{definition}
