        \stDgeqzero(X, \star) &= \{ K^\bullet \in \Dbc(X, \star) : \scrH^i(K^\bullet) = 0 \text{ for all } i < 0 \},

    For rational coefficients, the objects of $\Dbc(X, E)$\CrefIfExists{definition:derived_category_of_cohomologically_bounded_constructible_sheaves_with_rational_adic_coefficients_on_a_noetherian_scheme} are those of $\Dbc(X, R)$, so the vanishing conditions on cohomology sheaves are identical.     For algebraic coefficients, every object of $\Dbc(X, K)$\CrefIfExists{definition:derived_category_of_cohomologically_bounded_constructible_sheaves_with_rational_adic_coefficients_on_a_noetherian_scheme} descends to some finite extension $L/K$. The vanishing conditions on cohomology sheaves are preserved under base change along $L' / L$, so the subcategories $(\stDleqzero(X, K), \stDgeqzero(X, K))$ form a $t$-structure as the 2-direct limit of the $t$-structures on $\Dbc(X, L)$.

    We write \hl{$\sttauleqn$} and \hl{$\sttaugeqn$} for the truncation functors of this $t$-structure. The lower truncation functor $\sttauleqn$ is the Deligne truncation functor (see Lemma {\cite[II.6.1]{kiehl_weissauer_wcps}}).
