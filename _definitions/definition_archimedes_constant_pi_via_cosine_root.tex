\begin{definition} \label{definition:archimedes_constant_pi_via_cosine_root}
The \hldef{Archimedes' constant} \hl{$\pi$}, usually called \hldef{pi}, is the real number defined by
$$\pi = 2 \cdot \inf\{x > 0 : \cos(x) = 0\}$$
where $\cos : \mathbb{R} \to \mathbb{R}$ is the \CrefAndHyperrefIfExist{definition:sine_and_cosine_functions_on_real_line_via_power_series}{real cosine function}. The set $\{x > 0 : \cos(x) = 0\}$ has a unique \CrefAndHyperrefIfExist{definition:least_element_in_a_subset_of_a_partially_ordered_set}{minimum}, so the \CrefAndHyperrefIfExist{definition:supremum_infimum_of_a_subset_of_an_ordered_set}{infimum} is attained.
\end{definition}
