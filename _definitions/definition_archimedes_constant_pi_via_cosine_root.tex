The \hldef{Archimedes' constant $\pi$} is the real number defined by
$$\hlin{\pi = 2 \cdot \inf\{x > 0 : \cos(x) = 0\}}$$
where $\cos : \mathbb{R} \to \mathbb{R}$ is the \CrefAndHyperrefIfExist{definition:sine_and_cosine_functions_on_real_line_via_power_series}{real cosine function}. The set $\{x > 0 : \cos(x) = 0\}$ has a unique minimum, so the infimum is attained.
