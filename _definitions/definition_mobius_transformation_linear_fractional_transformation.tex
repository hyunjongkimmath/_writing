\begin{definition}[Möbius transformation, linear fractional transformation] \label{definition:mobius_transformation_linear_fractional_transformation}
    Let $\bbC_\infty = \mathbb{P}^1(\bbC) = \bbC \cup \{\infty\}$ be the \CrefAndHyperrefIfExist{definition:riemann_sphere}{Riemann sphere}. A \hldef{Möbius transformation} (also called a \hldef{linear fractional transformation}) is a bijection $f : \bbC_\infty \to \bbC_\infty$ of the form
    $$f(z) = \frac{az + b}{cz + d}$$

    where $a, b, c, d \in \bbC$ satisfy $ad - bc \neq 0$. Two quadruples $(a,b,c,d)$ and $(a',b',c',d')$ define the same Möbius transformation if and only if they differ by a nonzero scalar multiple. Equivalently, the group of Möbius transformations is isomorphic to $\operatorname{PGL}_2(\bbC) \cong \operatorname{PSL}_2(\bbC)$, acting on $\mathbb{P}^1(\bbC)$ via linear fractional transformations.
\end{definition}
