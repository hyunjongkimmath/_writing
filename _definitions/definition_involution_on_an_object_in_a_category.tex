\begin{definition} \label{definition:involution_on_an_object_in_a_category}
Let $\mathcal{C}$ be a \CrefAndHyperrefIfExist{definition:category}{category}. 
An \hldef{involution on an object $X \in \operatorname{Ob}(\mathcal{C})$} is an automorphism $i: X \to X$ such that $i \circ i = \operatorname{id}_X$.
\end{definition}
