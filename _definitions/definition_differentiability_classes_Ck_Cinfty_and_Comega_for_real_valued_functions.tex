\begin{definition} \label{definition:differentiability_classes_Ck_Cinfty_and_Comega_for_real_valued_functions}

    Let $U \subseteq \mathbb{R}$ be an open set and let $f : U \to \mathbb{R}$ be a \CrefAndHyperrefIfExist{definition:function_of_sets}{function}. For $k \in \mathbb{N}$, we say that $f$ is \hldef{$C^k$ on $U$} (or \hldef{$k$ times continuously differentiable on $U$}) if all derivatives $f', f'', \dots, f^{(k)}$ (defined inductively as successive applications of the \CrefAndHyperrefIfExist{definition:derivative_of_a_real_valued_function_on_a_real_interval}{derivative}) exist and are \CrefAndHyperrefIfExist{definition:continuous_map_of_topological_spaces}{continuous} on $U$.

    The function $f$ is called \hldef{$C^\infty$} (or \hldef{smooth}, or \hldef{infinitely differentiable}) if it is $C^k$ for every $k \in \mathbb{N}$.

    The function $f$ is called \hldef{$C^\omega$} (or \hldef{real analytic}) if it is \CrefAndHyperrefIfExist{definition:real_analytic_function_on_an_open_interval}{real analytic} on $U$.

    These classes satisfy the strict inclusions
    $$C^\omega \subsetneq C^\infty \subsetneq \cdots \subsetneq C^{k+1} \subsetneq C^k \subsetneq \cdots \subsetneq C^0,$$
    where $C^0$ denotes the space of continuous functions on $U$.
\end{definition}
