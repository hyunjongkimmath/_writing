Let $\mathcal{C}$ be a \CrefAndHyperrefIfExist{definition:locally_small_category}{locally small category}. 
We say $\mathcal{C}$ is a \hldef{pre-Galois category} if it satisfies the following conditions:
\begin{enumerate}
    \item $\mathcal{C}$ has a \CrefAndHyperrefIfExist{definition:initial_final_zero_objects_of_a_category}{terminal object} and all \CrefAndHyperrefIfExist{definition:finite_morphism_of_schemes}{finite} \CrefAndHyperrefIfExist{definition:cartesian_product_of_two_objects_in_a_category_over_an_object}{pullbacks} exist.

    \item $\mathcal{C}$ has finite \CrefAndHyperrefIfExist{definition:product_and_coproduct_of_objects_in_a_category}{coproducts}, including an \CrefAndHyperrefIfExist{definition:initial_final_zero_objects_of_a_category}{initial object}, and the quotient of any object by a finite group of automorphisms exists.

    \item Every morphism $f: X \to Y$ in $\mathcal{C}$ can be written as a composition $X \xrightarrow{p} Z \xrightarrow{i} Y$ where $p$ is a strict epimorphism and $i$ is a \CrefAndHyperrefIfExist{definition:monomorphism_and_epimorphism_in_categories}{monomorphism} which is an isomorphism onto a connected component of $Y$. 
\end{enumerate}

\end{definition}
