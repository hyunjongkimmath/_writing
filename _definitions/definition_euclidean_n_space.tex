\begin{definition} \label{definition:euclidean_n_space}
For a positive integer $n$, let \hl{$\mathbb{R}^n$} denote the $n$-fold Cartesian product of the \CrefAndHyperrefIfExist{definition:field_of_real_numbers}{real line} $\mathbb{R}$ with itself:
$$\hlin{\mathbb{R}^n = \{ (x_1, x_2, \dots, x_n) : x_i \in \mathbb{R} \text{ for all } i=1,\dots,n \}}.$$ 
The set $\mathbb{R}^n$ is called \hl{Euclidean n-space}. A point $x = (x_1, \dots, x_n) \in \mathbb{R}^n$ is associated with the \hl{Euclidean norm}
$$\hlin{\|x\| = \sqrt{x_1^2 + x_2^2 + \dots + x_n^2}}.$$ 
The corresponding \CrefAndHyperrefIfExist{definition:extended_metric_on_a_set}{metric} $d : \mathbb{R}^n \times \mathbb{R}^n \to [0,\infty)$ is given by
$$\hlin{d(x,y) = \|x - y\|}.$$ 
This metric \CrefAndHyperrefIfExist{definition:topology_induced_by_an_extended_metric_and_open_ball_for_an_extended_metric}{induces} the standard topology on $\mathbb{R}^n$, called the \hldef{Euclidean topology}. 

\TextIfExists{definition:product_topology_on_a_cartesian_product_of_topological_spaces}{
    The Euclidean topology on $\mathbb{R}^n$ coincides with the \CrefAndHyperrefIfExist{definition:product_topology_on_a_cartesian_product_of_topological_spaces}{product topology} of $\prod_{i=1}^n \mathbb{R}$ where each copy of $\bbR$ is eqiupped with its Euclidean topology.
}
\end{definition}
