\begin{definition}[Probability measure space] \label{definition:probability_measure_space_for_a_measure_on_a_measurable_space}
Let $(X, \mathcal{A}, \mu)$ be a \CrefAndHyperrefIfExist{definition:measure_on_a_measurable_space_and_measure_space}{measure space}.

The measure $\mu$ is called a \hldef{probability measure} if
$$\mu(X) = 1.$$
A \hldef{probability measure space} is a measure space $(X, \mathcal{A}, \mu)$ with $\mu(X) = 1$.
\end{definition}
