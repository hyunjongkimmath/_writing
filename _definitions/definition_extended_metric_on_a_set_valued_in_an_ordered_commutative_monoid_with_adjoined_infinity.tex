\begin{definition}[Extended metric on a set valued in an ordered semiring with adjoined infinity] \label{definition:extended_metric_on_a_set_valued_in_an_ordered_commutative_monoid_with_adjoined_infinity}
    Let $M$ be a set and let $T$ be an \CrefAndHyperrefIfExist{definition:ordered_monoid}{ordered commutative monoid}. Let $T^\infty$ be the \CrefAndHyperrefIfExist{definition:ordered_monoid_with_adjoined_infinity}{ordered commutative monoid with adjoined infinity} obtained from $T$.

    An \hldef{extended metric on $M$ valued in $T^\infty$} is a function
    $$d : M \times M \to T^\infty$$
    such that for all $x,y,z \in M$:
    \begin{enumerate}
        \item \textbf{Non-negativity and identity of indiscernibles:} \quad $d(x,y) \geq 0_T$, and $d(x,y) = 0_T$ if and only if $x = y$.
        \item \textbf{Symmetry:} \quad $d(x,y) = d(y,x)$.
        \item \textbf{Triangle inequality:} \quad $d(x,z) \leq d(x,y) + d(y,z)$,
    \end{enumerate}
    where addition and order are those of $T^\infty$, and the convention that sums involving $\infty$ behave so that $t + \infty = \infty$ for any $t \in T^\infty$. A set equipped with an extended metric valued in $T^\infty$ is called an \hldef{extended metric space valued in $T^\infty$}.

    If the range of $d$ is contained in $T$, then we call it a \hldef{metric on $M$ valued in $T$}, with $M$ called a \hldef{metric space valued in $T$}.

    An \hldef{extended metric on $M$} without reference to a valued a specific choice of $T$ almost usually refers to the standard notion of extended metric on $M$ valued in $T = \bbR_{\geq 0} = [0,\infty]$\CrefIfExists{definition:field_of_real_numbers}\CrefIfExists{definition:positive_cone_in_an_ordered_monoid}\CrefIfExists{proposition:positive_cone_of_ordered_ring_is_ordered_semiring}. 
    % we recover the standard definition of an extended metric taking values in $\bbR_{\geq 0}$ or $[0,\infty]$.

    An extended metric space has a natural \CrefAndHyperrefIfExist{definition:topological_space}{topological space} structure\CrefIfExists{definition:topology_induced_by_an_extended_metric_valued_in_an_ordered_commutative_monoid_with_adjoined_infinity_and_open_ball_for_an_extended_metric}.
\end{definition}
