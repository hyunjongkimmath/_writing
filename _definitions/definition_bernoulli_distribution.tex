\begin{definition}[Bernoulli distribution] \label{definition:bernoulli_distribution}

Let $p \in [0, 1]$. A real-valued random variable $X$ on a \CrefAndHyperrefIfExist{definition:probability_measure_space_for_a_measure_on_a_measurable_space}{probability measure space} has the \hldef{Bernoulli distribution with parameter $p$} (denoted \hl{$\operatorname{Bern}(p)$}) if
$$P(X = 1) = p \quad \text{and} \quad P(X = 0) = 1 - p.$$

The \CrefAndHyperrefIfExist{definition:expectation_of_a_random_variable_on_a_probability_measure_space}{expectation} is $\mathbb{E}[X] = p$, and the \CrefAndHyperrefIfExist{definition:variance_and_covariance}{variance} is $\operatorname{Var}(X) = p(1 - p)$.
\end{definition}
