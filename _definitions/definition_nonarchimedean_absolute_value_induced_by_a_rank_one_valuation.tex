\begin{definition} \label{definition:nonarchimedean_absolute_value_induced_by_a_rank_one_valuation}
    Let $K$ be a \CrefAndHyperrefIfExist{definition:field}{field} and let $v: K \to \mathbb{R} \cup \{\infty\}$ be a \CrefAndHyperrefIfExist{definition:valuation_on_a_field}{valuation} (of rank $1$). Fix a real number $c$ with $0 < c < 1$. The function
    $$ |x|_v := \begin{cases} c^{v(x)} & \text{if } x \in K^\times \\ 0 & \text{if } x = 0 \end{cases} $$
    is a \CrefAndHyperrefIfExist{definition:archimedean_and_nonarchimedean_extended_metrics_on_sets_valued_in_ordered_commutative_monoid_with_adjoined_infinity}{nonarchimedean} \CrefAndHyperrefIfExist{definition:absolute_value_on_a_ring_valued_in_an_ordered_semiring}{absolute value} on $K$. 

    Different values of $c$ yield \CrefAndHyperrefIfExist{definition:equivalent_absolute_values_on_a_field}{equivalent absolute values} and thus do not change the \CrefAndHyperrefIfExist{definition:topology_on_a_field_induced_by_an_absolute_value}{topology induced by $|\cdot|_v$}
\end{definition}
