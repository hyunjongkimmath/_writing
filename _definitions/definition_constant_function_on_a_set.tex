\begin{definition}[Constant function on a set] \label{definition:constant_function_on_a_set}
    Let $X$ and $Y$ be sets. A \CrefAndHyperrefIfExist{definition:function_of_sets}{function} $f : X \to Y$ is called \hldef{constant} if there exists an element $c \in Y$ such that $f(x) = c$ for all $x \in X$. In this case we write \hl{$f \equiv c$} and say that $f$ is the \hldef{constant function with value $c$}.
\end{definition}
