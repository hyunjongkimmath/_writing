\begin{definition}[Absolute Value on a ring] \label{definition:absolute_value_on_a_ring}
    Let $R$ be a \CrefAndHyperref{definition:commutative_ring}{commutative ring}.

    An \hldef{absolute value on $R$} is a \CrefAndHyperrefIfExist{definition:seminorm_on_a_commutative_ring}{seminorm} $|\cdot|: R \to \mathbb{R}_{\geq 0}$ on $R$ that additionally satisfies
    \begin{enumerate}
        \item Triangle inequality: $|a + b| \leq |a| + |b|$.
    \end{enumerate}

    % Let \( F \) be a \CrefAndHyperrefIfExist{definition:field}{field}. 
    % An \hldef{absolute value on $F$} is a function 
    % \[
    % | \cdot | : F \to \mathbb{R}_{\geq 0}
    % \]
    % that satisfies the following properties for all \( a, b \in F \):

    % \begin{enumerate}
    %     \item Non-negativity: \( |a| \geq 0 \),
    %     \item Positive-definiteness: \( |a| = 0 \iff a = 0 \),
    %     \item Multiplicativity: \( |ab| = |a| \cdot |b| \),
    %     \item Triangle inequality: \( |a + b| \leq |a| + |b| \).
    % \end{enumerate}

    % Here, \( 0 \) denotes the additive identity of the field \( F \), and the codomain \( \mathbb{R}_{\geq 0} \) consists of non-negative real numbers.


    A ring equipped with an absolute value may be called a \hldef{normed ring} or an \hldef{absolute valued ring}.

    A \CrefAndHyperrefIfExist{definition:field}{field} equipped with an absolute value may be called a \hldef{normed field}. It may also be called a \hldef{valued field}, but this should not be confused with the more algebraic notion of a field equipped with a \CrefAndHyperrefIfExist{definition:valuation_on_a_field}{valuation} with values in a more general ordered group.
\end{definition}
