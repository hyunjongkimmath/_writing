\begin{definition}[Geometric distribution] \label{definition:geometric_distribution}

Let $p \in (0, 1]$. A random variable $X$ on a \CrefAndHyperrefIfExist{definition:probability_measure_space_for_a_measure_on_a_measurable_space}{probability measure space} with codomain $\{1, 2, 3, \dots\}$ has the \hldef{geometric distribution with parameter $p$} (denoted \hl{$\operatorname{Geom}(p)$}) if for each $k \in \{1, 2, 3, \dots\}$,
$$P(X = k) = (1 - p)^{k - 1} p.$$

The \CrefAndHyperrefIfExist{definition:expectation_of_a_random_variable_on_a_probability_measure_space}{expectation} is $\mathbb{E}[X] = \tfrac{1}{p}$, and the \CrefAndHyperrefIfExist{definition:variance_and_covariance}{variance} is $\operatorname{Var}(X) = \tfrac{1 - p}{p^2}$.
\end{definition}
