\begin{definition}[Order topology on a partially ordered set] \label{definition:order_topology_on_a_partially_ordered_set}
    Let $(X, \leq)$ be a \CrefAndHyperrefIfExist{definition:partially_ordered_set}{partially ordered set}.

    For $a, b \in X$ with $a < b$, define the \hldef{open interval}
    $$\hlin{(a, b) := \{x \in X : a < x < b\}.}$$
    For $a \in X$, define the \hldef{upper ray} and \hldef{lower ray}
    $$\hlin{(-\infty, b) := \{x \in X : x < b\}, \qquad (a, \infty) := \{x \in X : x > a\}.}$$
    (When $X$ has a minimum element $-\infty_X$ or a maximum element $+\infty_X$, the rays $(-\infty, b)$ and $(a, \infty)$ are defined analogously with $-\infty_X$ and $+\infty_X$ as the bounds, respectively; in that case $(-\infty, b) = \{x \in X : x < b\}$ and $(a, \infty) = \{x \in X : x > a\}$ where the comparison uses the existing extremal elements.)

    The \hldef{order topology} on $X$ is the \CrefAndHyperrefIfExist{definition:topological_space}{topology} \CrefAndHyperrefIfExist{definition:topology_on_a_set_generated_by_a_collection_of_subsets_and_subbasis_for_a_topology}{generated by} the collection of all open intervals $(a, b)$ and all rays $(-\infty, b)$ and $(a, \infty)$. That is, a subset $U \subseteq X$ is open in the order topology if and only if for every $x \in U$, there exist $a, b \in X \cup \{-\infty_X, +\infty_X\}$ (where $-\infty_X, +\infty_X$ are formal symbols representing bounds outside $X$ if $X$ has no minimum/maximum) with $a < x < b$ such that $(a, b) \subseteq U$.

    If $(X, \leq)$ is a \CrefAndHyperrefIfExist{definition:total_order_linear_order_on_a_set}{totally ordered set} (or linearly ordered set), then the collection of all open intervals $(a, b)$ together with all rays $(-\infty, b)$ and $(a, \infty)$ forms a \CrefAndHyperrefIfExist{definition:basis_for_a_topology}{basis} for the order topology. In this case, a subset $U \subseteq X$ is open if and only if for every $x \in U$, there exist $a, b \in X \cup \{-\infty_X, +\infty_X\}$ with $a < x < b$ and $(a, b) \subseteq U$ (where we interpret $(-\infty, b)$ as the set of all $x < b$ and $(a, \infty)$ as the set of all $x > a$).
\end{definition}
