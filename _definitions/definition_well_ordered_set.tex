\begin{definition}[Well-ordered set] \label{definition:well_ordered_set}
A \hldef{well-ordered set} is a pair $(S, \leq)$ consisting of a \CrefAndHyperrefIfExist{definition:total_order_linear_order_on_a_set}{totally ordered set} in which every nonempty subset has a \CrefAndHyperrefIfExist{definition:least_element_in_a_subset_of_a_partially_ordered_set}{least element}. In other words, for every nonempty $A \subseteq S$, there exists $m \in A$ such that $m \leq x$ for all $x \in A$.
\end{definition}
