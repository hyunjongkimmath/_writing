\begin{definition}[Exponential distribution] \label{definition:exponential_distribution}

Let $\lambda > 0$. A real-valued random variable $X$ on a \CrefAndHyperrefIfExist{definition:probability_measure_space_for_a_measure_on_a_measurable_space}{probability measure space} has the \hldef{exponential distribution with rate $\lambda$} (denoted \hl{$\operatorname{Exp}(\lambda)$}) if its \CrefAndHyperrefIfExist{definition:distribution_of_a_random_variable_on_a_probability_measure_space}{distribution} is the measure on $\mathbb{R}$ given by
$$\hlin{\mu_X(A) = \int_A \lambda e^{-\lambda x} \mathbf{1}_{[0, \infty)}(x) \, dx}$$
for every Borel set $A \subseteq \mathbb{R}$.

The probability density function is $$f(x) = \lambda e^{-\lambda x} \mathbf{1}_{[0, \infty)}(x).$$ The \CrefAndHyperrefIfExist{definition:expectation_of_a_random_variable_on_a_probability_measure_space}{expectation} is $\mathbb{E}[X] = \tfrac{1}{\lambda}$, and the \CrefAndHyperrefIfExist{definition:variance_and_covariance}{variance} is $\operatorname{Var}(X) = \tfrac{1}{\lambda^2}$.
\end{definition}
