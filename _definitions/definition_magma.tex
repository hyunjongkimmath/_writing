\begin{definition}[Magma] \label{definition:magma}

A \hldef{magma} is a pair $(M, *)$ consisting of a set $M$ and a binary operation
$$* : M \times M \to M,$$
called the \hldef{magma operation}. No axioms (associativity, commutativity, identity) are assumed.

A magma is called \hldef{associative} if $(a * b) * c = a * (b * c)$ for all $a, b, c \in M$, in which case it is also called a \hldef{semigroup}.
\end{definition}
