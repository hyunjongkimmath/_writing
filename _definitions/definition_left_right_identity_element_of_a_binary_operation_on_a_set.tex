\begin{definition} \label{definition:left_right_identity_element_of_a_binary_operation_on_a_set}
    % EDITOR APPROVED
Let $S$ be a \CrefAndHyperrefIfExist{definition:zermelo_fraenkel_set_theory}{set} equipped with a \CrefAndHyperrefIfExist{definition:n_ary_operation_binary_operation_ternary_operation_on_a_set}{binary operation} $\cdot : S \times S \to S$. An element $e \in S$ is called a \hldef{left identity element} if $e \cdot x = x$ for all $x \in S$. Similarly, an element $e \in S$ is called a \hldef{right identity element} if $x \cdot e = x$ for all $x \in S$. An element $e \in S$ is called an \hldef{identity element} (or \hldef{neutral element}) if it is both a left and a right identity element. 
If an identity element of $\cdot$ exists, then it is unique\CrefIfExists{lemma:identity_element_of_a_binary_operation_on_a_set_is_unique_if_exists}.
\end{definition}
