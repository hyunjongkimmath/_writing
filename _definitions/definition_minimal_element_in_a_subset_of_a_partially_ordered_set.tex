\begin{definition} \label{definition:minimal_element_in_a_subset_of_a_partially_ordered_set}
Let $(X, \leq)$ be a \CrefAndHyperrefIfExist{definition:partially_ordered_set}{partially ordered set} and let $A \subseteq X$ be a subset. An element $m \in A$ is a \hldef{minimal element of $A$} if there is no element $x \in A$ such that $x < m$, i.e.\ if the condition $x \leq m$ for some $x \in A$ implies $x = m$.
\end{definition}
