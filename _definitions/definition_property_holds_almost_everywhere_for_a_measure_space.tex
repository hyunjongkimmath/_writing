\begin{definition} \label{definition:property_holds_almost_everywhere_for_a_measure_space}
Let $(X, \mathcal{A}, \mu)$ be a \CrefAndHyperrefIfExist{definition:measure_on_a_measurable_space_and_measure_space}{measure space} and let $P$ be a property that may or may not hold for points of $X$.

We say that $P$ \hldef{holds almost everywhere} (or holds \hldef{$\mu$-a.e.}) if there exists a $\mu$-null set $N \in \mathcal{A}$ such that
$$P(x) \text{ holds for all } x \in X \setminus N.$$

Equivalently, the set
$$\{ x \in X : P(x) \text{ fails} \}$$
is contained in some \CrefAndHyperrefIfExist{definition:null_set_and_null_collection_for_a_measure_on_a_measurable_space}{$\mu$-null set} (i.e.\ the failure set belongs to the null collection $\mathcal{N}_\mu$ of \CrefAndHyperrefIfExist{definition:null_set_and_null_collection_for_a_measure_on_a_measurable_space}{null set and null collection}).
\end{definition}
