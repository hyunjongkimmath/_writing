\begin{definition}[Algebraic integer] \label{definition:algebraic_integer}
An element $\alpha$ of the \CrefAndHyperrefIfExist{definition:algebraically_closed_field}{algebraic closure} $\overline{\mathbb{Q}}$ of $\mathbb{Q}$ is called an \hldef{algebraic integer} if it is a root of a monic polynomial in the \CrefAndHyperrefIfExist{definition:polynomial_ring_over_a_commutative_ring}{polynomial ring} $\mathbb{Z}[x]$. That is, there exist $n \geq 1$ and integers $a_0, a_1, \dots, a_{n-1} \in \mathbb{Z}$ such that
$$\alpha^n + a_{n-1}\alpha^{n-1} + \cdots + a_1\alpha + a_0 = 0.$$

Equivalently, $\alpha$ is an algebraic integer if and only if the \CrefAndHyperrefIfExist{definition:algebraic_element_minimal_polynomial_of_an_algebraic_element_algebraic_field_extension_transcendental_element_field_extension}{minimal polynomial of $\alpha$ over $\mathbb{Q}$} lies in $\mathbb{Z}[x]$ (i.e.\ has integer coefficients). The set of all algebraic integers is denoted by \hl{$\overline{\mathbb{Z}}$} and forms a \CrefAndHyperrefIfExist{definition:subring_of_a_ring}{subring} of $\overline{\mathbb{Q}}$.
\end{definition}
