\begin{definition} \label{definition:trace_of_a_matrix_over_a_ring}

    Let $R$ be a \CrefAndHyperrefIfExist{definition:ring}{(not necessarily commutative) ring}, and let $n \in \mathbb{N}_{\geq 1}$. For any square matrix $A = (a_{ij}) \in M_{n,n}(R)$, the \hldef{trace of $A$} is the element
    $$\hlin{\operatorname{tr}(A) = \sum_{i=1}^n a_{ii}}$$
    in $R$.

    The trace map $\operatorname{tr}: M_{n,n}(R) \to R$ is additive: $\operatorname{tr}(A + B) = \operatorname{tr}(A) + \operatorname{tr}(B)$ for all $A, B \in M_{n,n}(R)$. If $R$ is commutative, then the trace satisfies the cyclic property
    $$\operatorname{tr}(AB) = \operatorname{tr}(BA)$$
    for all $A, B \in M_{n,n}(R)$, and more generally $\operatorname{tr}(A_1 A_2 \cdots A_k) = \operatorname{tr}(A_2 \cdots A_k A_1)$ for any cyclic permutation of a product.
\end{definition}
