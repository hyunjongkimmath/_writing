\begin{definition} \label{definition:tangent_function_on_real_line}
The \hldef{tangent function}, denoted by \hl{$\tan$}, is the function
$$\tan(x) = \frac{\sin(x)}{\cos(x)}$$
defined on the open set $\{x \in \mathbb{R} : \cos(x) \neq 0\} = \mathbb{R} \setminus \{\frac{\pi}{2} + k\pi : k \in \mathbb{Z}\}$, where $\sin$ and $\cos$ are the \CrefAndHyperrefIfExist{definition:sine_and_cosine_functions_on_real_line_via_power_series}{sine and cosine functions}. The function is $\pi$-periodic.
\end{definition}
