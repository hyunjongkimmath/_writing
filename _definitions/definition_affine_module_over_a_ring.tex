\begin{definition} \label{definition:affine_module_over_a_ring}
    Let $R$ be a \CrefAndHyperrefIfExist{definition:ring}{ring}. 
    An \hldef{affine module} is a set $A$ together with an \CrefAndHyperrefIfExist{definition:module_of_a_ring}{$R$-module} $M$ such that there is a \CrefAndHyperref{definition:left_and_right_group_actions_on_a_set}{group action} of $M$ on $A$, say written as $a + m$, such that for any two $a,b \in A$, there is a unique $m$ such that $b = a+m$. In other words, $A$ is a \CrefAndHyperref{definition:principal_homogeneous_space_torsor_for_a_group}{principal homogeneous space} for the group $M$. One might denote the value $m$ in this case as \hl{$b - a$}.
    
    The module $M$ may be called the \hldef{underlying module}, the \hldef{direction module}, the \hldef{translation module}, the \hldef{model module}, etc., of the affine module structure.

    An \hldef{affine vector space} is an affine module whose underlying module is a \CrefAndHyperrefIfExist{definition:vector_space_over_a_field}{vector space} over a \CrefAndHyperrefIfExist{definition:field}{field}.
\end{definition}
