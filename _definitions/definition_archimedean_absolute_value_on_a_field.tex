\begin{definition} \label{definition:archimedean_absolute_value_on_a_field}
    Let $F$ be a \CrefAndHyperrefIfExist{definition:field}{field}. An \CrefAndHyperrefIfExist{definition:absolute_value_on_a_field}{absolute value $|\cdot|$ on $F$} is said to be \hldef{non-archimedean} if 
    $$|x+y| \leq \max(|x|, |y|) \quad \text{for all } x,y \in F$$
    and is said to be \hldef{archimedean} otherwise.

    Equivalently, $|\cdot$ is non-archimedean if and only if its \CrefAndHyperrefIfExist{definition:metric_induced_by_an_absolute_value_on_a_field}{induced metric} is \CrefAndHyperrefIfExist{definition:archimedean_and_nonarchimedean_metrics_on_sets}{non-archimedean}.

    In particular, a \hldef{non-archimedean valued field} (resp. \hldef{archimedean valued field}) is a \CrefAndHyperrefIfExist{definition:absolute_value_on_a_field}{valued field} whose valuation is non-archimedean (resp. archimedean)
\end{definition}
