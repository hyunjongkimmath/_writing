\begin{definition}[Independence of random variables on a probability space] \label{definition:independence_of_random_variables_on_a_probability_space}
Let $(\Omega, \mathcal{F}, P)$ be a \CrefAndHyperrefIfExist{definition:probability_space}{probability space}.

A finite collection of real-valued random variables $X_1, X_2, \dots, X_n$ on $(\Omega, \mathcal{F}, P)$ is called \hldef{independent} if the sub-$\sigma$-algebras $\sigma(X_1), \sigma(X_2), \dots, \sigma(X_n)$ are \CrefAndHyperrefIfExist{definition:independence_of_sigma_algebras}{independent}, where for each $i$,
$$\sigma(X_i) = \{\omega \in \Omega : X_i(\omega) \in B\} : B \in \mathcal{B}(\mathbb{R})\}$$
is the $\sigma$-algebra generated by $X_i$, and $\mathcal{B}(\mathbb{R})$ is the \CrefAndHyperrefIfExist{definition:borel_sigma_algebra_of_a_topological_space}{Borel $\sigma$-algebra} on $\mathbb{R}$.

An arbitrary (possibly infinite) collection of random variables $\{X_j\}_{j \in J}$ is called \hldef{independent} if every finite subcollection is independent.

A sequence $(X_n)_{n=1}^\infty$ of random variables is called an \hldef{independent sequence} if the set $\{\sigma(X_1), \sigma(X_2), \dots\}$ consists of independent $\sigma$-algebras.

Equivalently, $X_1, X_2, \dots, X_n$ are independent if and only if for every choice of Borel sets $B_1, B_2, \dots, B_n \in \mathcal{B}(\mathbb{R})$,
$$P\left(\bigcap_{i=1}^n \{\omega : X_i(\omega) \in B_i\}\right) = \prod_{i=1}^n P(\{\omega : X_i(\omega) \in B_i\}).$$
\end{definition}
