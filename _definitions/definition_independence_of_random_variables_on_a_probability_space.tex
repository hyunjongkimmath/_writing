\begin{definition}[Independence of random variables on a probability space] \label{definition:independence_of_random_variables_on_a_probability_space}
Let $(\Omega, \mathcal{F}, P)$ be a \CrefAndHyperref{definition:probability_space}{probability space}.

A finite collection of real-valued random variables $X_1, X_2, \dots, X_n$ on $(\Omega, \mathcal{F}, P)$ is called \hldef{independent} if for every choice of intervals $I_1, I_2, \dots, I_n \subseteq \mathbb{R}$,
$$P\left(\{\omega : X_1(\omega) \in I_1\} \cap \{\omega : X_2(\omega) \in I_2\} \cap \cdots \cap \{\omega : X_n(\omega) \in I_n\}\right) = P(X_1 \in I_1) P(X_2 \in I_2) \cdots P(X_n \in I_n).$$

An arbitrary (possibly infinite) collection of random variables $\{X_j\}_{j \in J}$ is called \hldef{independent} if every finite subcollection is independent.

A sequence $(X_n)_{n=1}^\infty$ of random variables is called an \hldef{independent sequence} if every finite subcollection is independent.
\end{definition}
