\begin{definition} \label{definition:quotient_map_of_a_set_by_an_equivalence_relation}
Let $\sim$ be an \CrefAndHyperrefIfExist{definition:equivalence_relation_on_a_set}{equivalence relation} on a set $X$, and let $X/{\sim}$ be the \CrefAndHyperrefIfExist{definition:equivalence_class_of_an_element_of_a_set_under_an_equivalence_relation_and_quotient_of_set_by_equivalence_relation}{quotient set}. The \hldef{quotient map} (or \hldef{canonical projection}) is the \CrefAndHyperrefIfExist{definition:function_of_sets}{function}
$$\hlin{\pi : X \to X/{\sim}, \quad \pi(x) = [x],}$$
where $[x]$ denotes the \CrefAndHyperrefIfExist{definition:equivalence_class_of_an_element_of_a_set_under_an_equivalence_relation_and_quotient_of_set_by_equivalence_relation}{equivalence class} of $x$.
\end{definition}
