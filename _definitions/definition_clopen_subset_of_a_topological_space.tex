\begin{definition} \label{definition:clopen_subset_of_a_topological_space}
Let $X$ be a \CrefAndHyperrefIfExist{definition:category_of_topological_spaces}{topological space}.
A subset $U \subseteq X$ is a \hldef{clopen subset} if $U$ is both an open set and a closed set in the topology of $X$.
\end{definition}
