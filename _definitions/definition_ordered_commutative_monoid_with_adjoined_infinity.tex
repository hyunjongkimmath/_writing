\begin{definition}[Ordered monoid with adjoined infinity] \label{definition:ordered_monoid_with_adjoined_infinity}
    Let $T$ be an \CrefAndHyperrefIfExist{definition:ordered_commutative_monoid}{ordered commutative monoid}. Define the set
    $$\hlin{T^\infty = T \cup \{\infty\},}$$
    where $\infty$ is a formal element not in $T$.

    We extend the addition on $T$ to $T^\infty$ by the following conventions for all $t \in T$:
    $$t + \infty = \infty + t = \infty \quad \text{and} \quad \infty + \infty = \infty.$$

    We extend the order on $T$ to $T^\infty$ by setting $t \leq \infty$ for all $t \in T$, so that $\infty$ is the largest element of $T^\infty$. With these operations and order, $T^\infty$ is an \hldef{ordered monoid with adjoined infinity}. The underlying partially ordered set of $T^\infty$ is precisely the \CrefAndHyperrefIfExist{definition:partially_ordered_set_with_adjoined_infinity}{partially ordered set with adjoined infinity} obtained from the underlying partial order of $T$.
\end{definition}
