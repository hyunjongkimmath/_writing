\begin{definition}[Fixed Point Set] \label{definition:fixed_point_set_of_a_group_acting_on_a_set}

Let $(G,\cdot)$ be a \CrefAndHyperrefIfExist{definition:left_and_right_group_actions_on_a_set}{group acting on} a set $X$, say on the left. 
For $H \subseteq G$, the \hldef{fixed point set of $H$ in $X$} or the \hldef{set of $H$-invariants in $X$} is defined by
$$\hlin{X^H = \{ x \in X : h \cdot x = x \text{ for all } h \in H \}}.$$
\end{definition}
