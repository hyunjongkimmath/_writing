\begin{definition}[Entire function on complex space] \label{definition:entire_function_on_complex_space}
Let $n,m \geq 1$ be integers, and let $f : \bbC^n \to \bbC^m$ be a function. The function $f$ is called \hldef{entire on $\bbC^n$} if it is \CrefAndHyperrefIfExist{definition:holomorphic_function_from_a_subset_of_Cn_to_Cm_and_derivative_of_a_holomorphic_function_at_a_point}{holomorphic on all of $\bbC^n$}.
\end{definition}
