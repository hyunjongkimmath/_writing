\begin{definition} \label{definition:dagger_object_in_a_category}

Let $\mathcal{C}$ be a \CrefAndHyperrefIfExist{definition:category}{category}. 

A \hldef{dagger object in $\calC$} is an object $X$ equipped with a functor $(\cdot)^*: \calC^{\op} \to \calC$ 

together with an isomorphism $i: X \to X^*$ such that the following diagram commutes:
$$X \xrightarrow{i} X^* \xrightarrow{i^*} X^{**} \cong X = \id_X$$

is an automorphism $i: X \to X$ such that $i \circ i = \operatorname{id}_X$.
\end{definition}
