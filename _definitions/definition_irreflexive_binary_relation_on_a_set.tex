\begin{definition} \label{definition:irreflexive_binary_relation_on_a_set}
Let $R$ be a \CrefAndHyperrefIfExist{definition:n_ary_relation_on_sets}{binary relation} on a set $X$. $R$ is \hldef{irreflexive} if for all $x \in X$, $\lnot (x R x)$. Equivalently, $R \cap \Delta_X = \varnothing$, where $\Delta_X$ is the \CrefAndHyperrefIfExist{definition:diagonal_relation_on_a_set}{diagonal relation} on $X$.
