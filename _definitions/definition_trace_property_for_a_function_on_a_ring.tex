\begin{definition} \label{definition:trace_property_for_a_function_on_a_ring}
    Let $f: R \to S$ be a \CrefAndHyperrefIfExist{definition:function_of_sets}{function} from a \CrefAndHyperrefIfExist{definition:ring}{ring} to a \CrefAndHyperrefIfExist{definition:zermelo_fraenkel_set_theory}{set}. We say that it satisfies the \hldef{trace property} if 
    $$f(ab) =f(ba)$$
    for all $a,b \in R$.
\end{definition}
