\begin{definition} \label{definition:standard_absolute_value_on_real_numbers_standard_topology_on_real_numbers}
    Let $\bbR$ be the \CrefAndHyperrefIfExist{definition:real_numbers_as_cauchy_completion_of_rational_numbers}{field of real numbers} equipped with the \CrefAndHyperrefIfExist{definition:standard_order_on_real_numbers}{standard order}\CrefIfExists{proposition:the_field_of_real_numbers_is_a_totally_ordered_field}.

    The \hldef{standard absolute value on $\bbR$} is the function $|\,\cdot\,|_\bbR : \bbR \to \bbR_{\ge 0}$ given by
    $$\hlin{|x|_\bbR = \begin{cases} x & \text{if } x \ge 0, \\ -x & \text{if } x < 0. \end{cases}}$$
    When no confusion is possible, we write simply $|\,\cdot\,|$ for $|\,\cdot\,|_\bbR$.

    The standard absolute value on $\bbR$ is indeed an \CrefAndHyperrefIfExist{definition:absolute_value_on_a_ring_valued_in_an_ordered_semiring}{absolute value} on $\bbR$ (valued in $\bbR_{\geq 0}$\CrefIfExists{proposition:positive_cone_of_ordered_ring_is_ordered_semiring}) and extends the \CrefAndHyperrefIfExist{definition:absolute_value_on_rational_numbers}{absolute value on $\bbQ$} under the canonical embedding $\iota: \bbQ \hookrightarrow \bbR$: for every $q \in \bbQ$, we have $|\iota(q)|_\bbR = \iota(|q|_\bbQ)$\CrefIfExists{proposition:the_field_of_rational_numbers_embeds_into_the_field_of_real_numbers}.

    In particular, we may regard $\bbR$ as a \CrefAndHyperrefIfExist{definition:extended_metric_on_a_set_valued_in_an_ordered_commutative_monoid_with_adjoined_infinity}{metric space}\CrefIfExists{definition:metric_induced_by_an_absolute_value_on_a_commutative_ring} via the metric
    $$d: \bbR \times \bbR \to \bbR_{\geq 0}, \quad d(x,y) = |x-y|_\bbR$$
    and hence\CrefIfExists{definition:topology_induced_by_an_extended_metric_valued_in_an_ordered_commutative_monoid_with_adjoined_infinity_and_open_ball_for_an_extended_metric} as a \CrefAndHyperrefIfExist{definition:topological_space}{topological space}. This topology on $\bbR$ is called the \hldef{standard topology on $\bbR$}.
\end{definition}
