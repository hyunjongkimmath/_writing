\begin{definition}[Torsion Group] \label{definition:torsion_group}
Let $G$ be a group. An element $g \in G$ is called a \hldef{torsion element} if $\operatorname{ord}(g) < \infty$, i.e., if the order of $g$ (\CrefAndHyperref{definition:order_of_a_group_element}{the definition of the order of a group element}) is finite.

The group $G$ is called a \hldef{torsion group} (or \hldef{periodic group}) if every element of $G$ is a torsion element. Equivalently, $G$ is a torsion group if every cyclic subgroup of $G$ is finite.

A group $G$ is called a \hldef{torsion-free group} if the only torsion element in $G$ is the identity element $e$. Equivalently, every non-identity element of $G$ has infinite order.
\end{definition}
