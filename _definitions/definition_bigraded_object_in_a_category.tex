\begin{definition} \label{definition:bigraded_object_in_a_category}
    Let $\mathcal{C}$ be a \CrefAndHyperrefIfExist{definition:category}{category}.
    A \hldef{bigraded object in $\mathcal{A}$} is a collection of objects \hl{$E = \{E_{p,q}\}_{p,q \in \mathbb{Z}}$} in $\mathcal{A}$ indexed by pairs of integers.

    A bigraded object in $\calA$ can be regarded as a \CrefAndHyperrefIfExist{definition:graded_object_in_a_category}{graded object} of graded objects in $\calA$.
\end{definition}
