\begin{definition}[Filter on a set] \label{definition:filter_on_a_set}

    Let $S$ be a nonempty set. A nonempty collection $\mathcal{F}$ of subsets of $S$ is called a \hldef{filter on $S$} if it satisfies the following conditions:
    \begin{enumerate}
        \item The empty set is not in $\mathcal{F}$, i.e., $\emptyset \notin \mathcal{F}$.
        \item \textbf{Upward closure:} If $A \in \mathcal{F}$ and $A \subseteq B \subseteq S$, then $B \in \mathcal{F}$.
        \item \textbf{Finite intersection property:} If $A, B \in \mathcal{F}$, then $A \cap B \in \mathcal{F}$.
    \end{enumerate}

    The elements of a filter are called its \hldef{members}. A filter $\mathcal{F}$ is said to be \hldef{principal} (or \hldef{fixed}) if there exists a nonempty set $A \subseteq S$ such that
    $$\mathcal{F} = \{\, B \subseteq S \mid A \subseteq B \,\},$$
    in which case we also say $\mathcal{F}$ is the principal filter generated by $A$. If the singleton filter consisting of all subsets containing a single point $x \in S$ is written as
    $$\dot{x} = \{\, B \subseteq S \mid x \in B \,\},$$
    then every principal filter is an intersection of such point filters.

    A filter $\mathcal{F}$ is called a \hldef{free filter} (or \hldef{non-principal filter}) if the intersection of all its members is empty, i.e., $\bigcap_{A \in \mathcal{F}} A = \emptyset$.
\end{definition}
