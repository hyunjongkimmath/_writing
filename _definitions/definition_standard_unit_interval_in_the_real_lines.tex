\begin{definition} \label{definition:standard_unit_interval_in_the_real_lines}
The \hldef{standard unit interval} or the \hldef{closed unit interval}, denoted by \hl{$I$}, is the \CrefAndHyperrefIfExist{definition:subspace_of_a_topological_space}{subspace} of \CrefAndHyperrefIfExist{definition:euclidean_n_space}{$\mathbb{R}$} defined by:
$$I = [0, 1] = \{x \in \mathbb{R} \mid 0 \le x \le 1\}$$
(\Cref{definition:interval_in_the_real_line})
\end{definition}
