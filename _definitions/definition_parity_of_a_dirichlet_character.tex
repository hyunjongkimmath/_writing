\begin{definition}[Parity of a Dirichlet character] \label{definition:parity_of_a_dirichlet_character}

Let $\chi$ be a \CrefAndHyperrefIfExist{definition:dirichlet_character_modulo_a_nonnegative_integer}{Dirichlet character modulo $k$}. The \hldef{parity of $\chi$} is defined by $\chi(-1)$. If $\chi(-1) = 1$, then $\chi$ is said to be even and we set \hl{$a(\chi) = 0$}; if $\chi(-1) = -1$, then $\chi$ is said to be odd and we set \hl{$a(\chi) = 1$}.
