\begin{definition} \label{definition:filter_and_ultrafilter_on_a_boolean_algebra}
Let $B$ be a \CrefAndHyperrefIfExist{definition:boolean_algebra}{Boolean algebra}.
A \hldef{filter $F$ on $B$} is a non-empty subset $F \subseteq B$ such that $0 \notin F$, if $x, y \in F$ then $x \land y \in F$, and if $x \in F$ and $x \le y$ (where $x \le y$ is defined as $x \land y = x$) then $y \in F$. An \hldef{ultrafilter} is a filter $U$ that is maximal with respect to set inclusion.
\end{definition}
