\begin{definition}[Binomial distribution] \label{definition:binomial_distribution}

Let $n \in \mathbb{N}_{\geq 1}$ and $p \in [0, 1]$. A random variable $X$ on a \CrefAndHyperrefIfExist{definition:probability_measure_space_for_a_measure_on_a_measurable_space}{probability measure space} with codomain $\{0, 1, \dots, n\}$ has the \hldef{binomial distribution with parameters $n$ and $p$} (denoted \hl{$\operatorname{Bin}(n, p)$}) if for each $k \in \{0, 1, \dots, n\}$,
$$P(X = k) = \binom{n}{k} p^k (1 - p)^{n - k}.$$

The \CrefAndHyperrefIfExist{definition:expectation_of_a_random_variable_on_a_probability_measure_space}{expectation} is $\mathbb{E}[X] = np$, and the \CrefAndHyperrefIfExist{definition:variance_and_covariance}{variance} is $\operatorname{Var}(X) = np(1 - p)$.
\end{definition}
