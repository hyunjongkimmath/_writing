Let $(X, \leq)$ be a \CrefAndHyperrefIfExist{definition:partially_ordered_set}{partially ordered set} and let $A \subseteq X$ be a subset. An element $m \in A$ is a \hldef{maximal element of $A$} if there is no element $x \in A$ such that $m < x$, i.e.\ if the condition $m \leq x$ for some $x \in A$ implies $x = m$.
\end{definition}
