\begin{definition} \label{definition:functional_on_a_module_over_a_ring}

    Let $R$ be a \CrefAndHyperrefIfExist{definition:ring}{(not necessarily commutative) ring}, and let $M$ be an \CrefAndHyperrefIfExist{definition:module_of_a_ring}{$R$-module}.

    An element of the \CrefAndHyperrefIfExist{definition:dual_of_a_left_right_two_sided_module}{dual module} of $M$ is called a \hldef{functional on $M$} (or an \hldef{$R$-linear functional on $M$}).

    More explicitly:
    \begin{enumerate}
        \item If $M$ is a left $R$-module, then a \hldef{(right) linear functional on $M$} is an element of $M^\vee = \operatorname{Hom}_R(M, R)$; it is a map $\varphi: M \to R$ that is left $R$-linear.

        \item If $M$ is a right $R$-module, then a \hldef{(left) linear functional on $M$} is an element of ${}^\vee M = \operatorname{Hom}_R(M, R)$; it is a map $\varphi: M \to R$ that is right $R$-linear.
    \end{enumerate}

    When $R$ is a commutative ring, the distinction between left and right functionals disappears, and one simply speaks of \hldef{linear functionals on $M$}. If $R$ is a field $F$ and $V$ is an \CrefAndHyperrefIfExist{definition:vector_space_over_a_field}{$F$-vector space}, then elements of the dual vector space $V^\vee$ are called \hldef{linear functionals on $V$}.
\end{definition}
