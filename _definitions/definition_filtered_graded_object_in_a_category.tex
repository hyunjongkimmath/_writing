\begin{definition} \label{definition:filtered_graded_object_in_a_category}
    Let $(M, F)$ be a \CrefAndHyperrefIfExist{definition:filtration_on_an_object_of_a_category}{increasing (resp. decreasing) filtered object} in a \CrefAndHyperrefIfExist{definition:category}{category} $\mathcal{C}$. 
    If $M$ is a \CrefAndHyperrefIfExist{definition:graded_object_in_a_category}{graded object}, then the filtration is said to be \hldef{compatible with the grading} if each $F_p M$ (resp. $F^p M$) is a \CrefAndHyperrefIfExist{definition:graded_subobject_of_a_graded_object_of_a_category}{graded subobject} of $M$.
    A graded object equipped with a filtration compatible with the grading is called a \hldef{filtered graded object}.
\end{definition}
