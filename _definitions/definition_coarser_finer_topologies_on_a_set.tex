\begin{definition} \label{definition:coarser_finer_topologies_on_a_set}
Let $X$ be a set and let $\tau_1$ and $\tau_2$ be two \CrefAndHyperrefIfExist{definition:topological_space}{topologies on} $X$. 
The \CrefAndHyperrefIfExist{definition:topological_space}{topology} $\tau_1$ is said to be \hldef{coarser than $\tau_2$} (or $\tau_2$ is \hldef{finer than $\tau_1$)} if $\tau_1 \subseteq \tau_2$. This means that every \CrefAndHyperrefIfExist{definition:subset_of_a_set}{subset} of $X$ that is \CrefAndHyperrefIfExist{definition:topological_space}{open} with respect to $\tau_1$ is also open with respect to $\tau_2$.
\end{definition}
