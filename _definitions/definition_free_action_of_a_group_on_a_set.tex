\begin{definition}[Free action of a group on a set] \label{definition:free_action_of_a_group_on_a_set}
Let $(G,\cdot)$ be a \CrefAndHyperrefIfExist{definition:group}{group} \CrefAndHyperrefIfExist{definition:left_and_right_group_actions_on_a_set}{acting on the left} a set $X$. The action is called \hldef{free} if for every $x \in X$, the \CrefAndHyperrefIfExist{definition:stabilizer_of_an_element_of_a_set_under_a_group_action}{stabilizer} $\operatorname{Stab}_G(x)$ is trivial, i.e.,
$$\operatorname{Stab}_G(x) = \{e\}.$$
Equivalently, if $g \cdot x = x$ for some $x \in X$, then $g = e$. In other words, no non-identity element of $G$ fixes any point of $X$.
\end{definition}
