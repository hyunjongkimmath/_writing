\begin{definition}[Measure-preserving transformation on a probability space] \label{definition:measure_preserving_transformation_on_a_probability_space}

Let $(X, \mathcal{A}, \mu)$ be a \CrefAndHyperrefIfExist{definition:probability_measure_space_for_a_measure_on_a_measurable_space}{probability measure space}. A measurable map $T: X \to X$ is called a \hldef{measure-preserving transformation} if for every $A \in \mathcal{A}$,
$$\mu(T^{-1}(A)) = \mu(A).$$

The system $(X, \mathcal{A}, \mu, T)$ is called a \hldef{dynamical system on the probability space}. The transformation $T$ is said to be \hldef{ergodic} if for every $A \in \mathcal{A}$ with $T^{-1}(A) = A$, either $\mu(A) = 0$ or $\mu(A) = 1$.
\end{definition}
