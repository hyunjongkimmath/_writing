\begin{definition} \label{definition:cauchy_sequence_in_rational_numbers}
    Let $\bbQ$ be the \CrefAndHyperrefIfExist{definition:field_of_rational_numbers}{field of rational numbers} equipped with the \CrefAndHyperrefIfExist{definition:absolute_value_on_rational_numbers}{absolute value $|\,\cdot\,|$}.

    A \hldef{Cauchy sequence in $\bbQ$} is a sequence $(a_n)_{n=1}^\infty$ of rational numbers with the property that for every positive rational number $\varepsilon \in \bbQ_{> 0}$, there exists a natural number $N \in \bbN$ such that for all $m, n \ge N$,
    $$|a_m - a_n| < \varepsilon.$$

    The set
    $$\hlin{\mathcal{C}_\bbQ = \left\{ (a_n)_{n=1}^\infty \in \bbQ^\bbN : (a_n) \text{ is a Cauchy sequence in } \bbQ \right\}}$$
    is called the \hldef{set of Cauchy sequences in $\bbQ$}.

    We note that the definition of a Cauchy sequence in $\bbQ$ involves only the absolute value $|\,\cdot\,| : \bbQ \to \bbQ_{\ge 0}$ and the order on $\bbQ$, not the real numbers $\bbR$.
\end{definition}
