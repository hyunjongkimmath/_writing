\begin{definition} \label{definition:complete_measure_space}
Let $(X, \mathcal{A}, \mu)$ be a \CrefAndHyperrefIfExist{definition:measure_on_a_measurable_space_valued_in_the_extended_real_line_and_measure_space}{measure space}.

The measure $\mu$ is called \hldef{complete} if every subset of a $\mu$-null set is measurable; that is,
$$\hlin{\text{if } N \in \mathcal{A} \text{ with } \mu(N) = 0 \text{ and } A \subseteq N, \text{ then } A \in \mathcal{A}.}$$

Equivalently, the $\sigma$-algebra $\mathcal{A}$ contains all subsets of sets in the null collection $\mathcal{N}_\mu$ of \CrefAndHyperrefIfExist{definition:null_set_and_null_collection_for_a_measure_on_a_measurable_space}{null set and null collection}.

A measure space that is complete is called a \hldef{complete measure space}.
\end{definition}
