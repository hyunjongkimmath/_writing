\begin{definition}[Poisson distribution] \label{definition:poisson_distribution}

Let $\lambda > 0$. A random variable $X$ on a \CrefAndHyperrefIfExist{definition:probability_measure_space_for_a_measure_on_a_measurable_space}{probability measure space} with codomain $\{0, 1, 2, \dots\}$ has the \hldef{Poisson distribution with parameter $\lambda$} (denoted \hl{$\operatorname{Pois}(\lambda)$}) if for each $k \in \{0, 1, 2, \dots\}$,
$$P(X = k) = e^{-\lambda} \frac{\lambda^k}{k!}.$$

The \CrefAndHyperrefIfExist{definition:expectation_of_a_random_variable_on_a_probability_measure_space}{expectation} is $\mathbb{E}[X] = \lambda$, and the \CrefAndHyperrefIfExist{definition:variance_and_covariance}{variance} is $\operatorname{Var}(X) = \lambda$.
\end{definition}
