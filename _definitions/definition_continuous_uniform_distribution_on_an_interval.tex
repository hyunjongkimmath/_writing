\begin{definition}[Continuous uniform distribution on an interval] \label{definition:continuous_uniform_distribution_on_an_interval}

Let $a, b \in \mathbb{R}$ with $a < b$. A real-valued random variable $X$ on a \CrefAndHyperrefIfExist{definition:probability_measure_space_for_a_measure_on_a_measurable_space}{probability measure space} has the \hldef{continuous uniform distribution on $[a, b]$} (denoted \hl{$\operatorname{Unif}(a, b)$}) if its \CrefAndHyperrefIfExist{definition:distribution_of_a_random_variable_on_a_probability_measure_space}{distribution} is the measure on $\mathbb{R}$ given by
$$\mu_X(A) = \int_A \frac{1}{b - a} \mathbf{1}_{[a, b]}(x) \, dx$$
for every Borel set $A \subseteq \mathbb{R}$.

The probability density function is $$f(x) = \frac{1}{b - a} \mathbf{1}_{[a, b]}(x).$$ The \CrefAndHyperrefIfExist{definition:expectation_of_a_random_variable_on_a_probability_measure_space}{expectation} is $\mathbb{E}[X] = \tfrac{a + b}{2}$, and the \CrefAndHyperrefIfExist{definition:variance_and_covariance}{variance} is $\operatorname{Var}(X) = \tfrac{(b - a)^2}{12}$.
\end{definition}
