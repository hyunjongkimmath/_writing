\begin{definition}[q-Weil number] \label{definition:q_Weil_number}
Let $q = p^f$ be a prime power.

A \CrefAndHyperrefIfExist{definition:algebraic_integer}{algebraic integer} $\alpha$ is called a \hldef{$q$-Weil number of weight $w$}, for $w \in \mathbb{Z}$, if for every \CrefAndHyperrefIfExist{definition:field_homomorphism}{field embedding} $\sigma: \mathbb{Q}(\alpha) \hookrightarrow \mathbb{C}$, one has
$$|\sigma(\alpha)| = q^{w/2}.$$

Equivalently, $\alpha$ is a $q$-Weil number of weight $w$ if and only if all its \CrefAndHyperrefIfExist{definition:galois_conjugate_of_element_of_field_extension_in_algebraic_closure}{Galois conjugates} over $\mathbb{Q}$ have the same complex absolute value $q^{w/2}$. The weight $w$ is uniquely determined by $\alpha$ unless $\alpha = 0$, in which case any integer $w > 0$ satisfies the condition.

\end{definition}
