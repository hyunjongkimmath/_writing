\begin{definition}[Totally ordered abelian group] \label{definition:totally_ordered_abelian_group}
A \hldef{totally ordered abelian group} is a triple $(G, +, \leq)$ consisting of an \CrefAndHyperrefIfExist{definition:group}{abelian group} $(G, +)$ and a \CrefAndHyperrefIfExist{definition:total_order_linear_order_on_a_set}{total order} $\leq$ on $G$ such that the order is compatible with addition. That is, for all $a, b, c \in G$,
$$a \leq b \implies a + c \leq b + c.$$

The group operation is written additively and denoted by $+$. The identity element is denoted by $0$. An abelian group equipped with such an order is called a \hldef{totally ordered abelian group}.
\end{definition}
