\begin{definition} \label{definition:trivial_involution_on_an_object_in_a_category}
Let \hl{$\mathcal{C}$} be a \CrefAndHyperrefIfExist{definition:category}{category}. 
The \hldef{trivial involution on an object $C$ of $\calC$} simply refers to the identity map on $C$; note that it is an involution.
\end{definition}
