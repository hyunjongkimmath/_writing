\begin{definition} \label{definition:left_right_global_dimension_of_a_ring}
    Let $R$ be a \CrefAndHyperrefIfExist{definition:ring}{not necessarily commutative ring}.
The \hldef{left global dimension of $R$}, denoted \hl{$\operatorname{lgldim}(R)$}, is defined as:
$$\operatorname{lgldim}(R) = \sup \{ \operatorname{pd}_R(M) \mid M \in {}_R\mathsf{Mod} \}$$
(\Cref{definition:left_right_projective_injective_flat_dimension_of_a_module_over_a_ring})
The \hldef{right global dimension} \hl{$\operatorname{rgldim}(R)$} is defined similarly using right $R$-modules. 

When it is clear which global dimension is discussed, one may simply write  \hl{$\operatorname{gldim}(R)$}.
\end{definition}
