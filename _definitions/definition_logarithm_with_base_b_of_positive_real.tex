\begin{definition} \label{definition:logarithm_with_base_b_of_positive_real}
    Let $b \in \mathbb{R}$ with $b > 0$ and $b \neq 1$. The map $\varphi : \mathbb{R} \to (0, \infty)$ defined by $\varphi(x) = b^x$ is a bijection by \CrefAndHyperrefIfExist{proposition:base_b_exponentiation_is_bijective_from_R_to_positive_reals}{bijectivity of base-$b$ exponentiation}. The \hldef{logarithm with base $b$}, denoted by \hl{$\log_b : (0, \infty) \to \mathbb{R}$}, is the \CrefAndHyperrefIfExist{definition:injective_surjective_bijective_map_of_sets}{inverse function} to $\varphi$. That is, for all $y > 0$,
    $$\hlin{\log_b(y) = x \quad \iff \quad b^x = y}$$
    and for all $x \in \mathbb{R}$, we have $\log_b(b^x) = x$ and $b^{\log_b(y)} = y$. In other words,
    $$\log_b(b^x) = x \quad \text{for all } x \in \mathbb{R},$$
    and
    $$b^{\log_b(x)} = x \quad \text{for all } x > 0.$$

    When $b = e$\CrefIfExists{definition:euler_number_e_as_limit}, the logarithm with base $e$ coincides with the \CrefAndHyperrefIfExist{definition:real_natural_logarithm_function_as_inverse_of_real_exponential_function}{natural logarithm} $\ln : (0, \infty) \to \mathbb{R}$\TODO{AI generated, reference needed: proposition that $e^x = \exp(x)$ so the inverse of $x \mapsto e^x$ is exactly $\ln$}.
\end{definition}
