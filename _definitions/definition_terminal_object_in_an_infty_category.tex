    Let $\mathcal{C}$ be an \CrefAndHyperrefIfExist{definition:infty_category_quasi_category}{$\infty$-category}.

    An object $* \in \mathcal{C}$ is called a \hldef{terminal/final object of $\mathcal{C}$} if it is a \CrefAndHyperrefIfExist{definition:limit_and_colimit_for_a_map_from_a_simplicial_set_to_an_infty_category}{limit} of the empty diagram $\emptyset \to \mathcal{C}$. Equivalently, $*$ is terminal if for every object $X \in \mathcal{C}$, the \CrefAndHyperrefIfExist{definition:mapping_space_between_objects_of_a_simplicial_set}{mapping space} $\Map_{\mathcal{C}}(X, *)$ is contractible.

    Dually, an object $\emptyset \in \mathcal{C}$ is called an \hldef{initial object of $\mathcal{C}$} if it is a \CrefAndHyperrefIfExist{definition:limit_and_colimit_for_a_map_from_a_simplicial_set_to_an_infty_category}{colimit} of the empty diagram $\emptyset \to \mathcal{C}$. Equivalently, $\emptyset$ is initial if for every object $X \in \mathcal{C}$, the mapping space $\Map_{\mathcal{C}}(\emptyset, X)$ is contractible.
\end{definition}
