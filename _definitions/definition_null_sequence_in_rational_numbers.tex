\begin{definition} \label{definition:null_sequence_in_rational_numbers}
    Let $\bbQ$ be the \CrefAndHyperrefIfExist{definition:field_of_rational_numbers}{field of rational numbers} equipped with the \CrefAndHyperrefIfExist{definition:absolute_value_on_rational_numbers}{absolute value $|\,\cdot\,|$}.

    A \hldef{null sequence in $\bbQ$} (or a \hldef{sequence converging to $0$ in $\bbQ$}) is a \CrefAndHyperrefIfExist{definition:cauchy_sequence_in_rational_numbers}{Cauchy sequence} $(a_n)_{n=1}^\infty$ in $\bbQ$ with the property that for every positive rational number $\varepsilon \in \bbQ_{> 0}$, there exists a natural number $N \in \bbN$ such that for all $n \ge N$,
    $$|a_n| < \varepsilon.$$

    The set
    $$\hlin{\mathcal{N}_\bbQ = \left\{ (a_n)_{n=1}^\infty \in \mathcal{C}_\bbQ : (a_n) \text{ is a null sequence in } \bbQ \right\}}$$
    is called the \hldef{set of null sequences in $\bbQ$}.

    We note that the definition of convergence to $0$ in $\bbQ$ involves only the absolute value $|\,\cdot\,| : \bbQ \to \bbQ_{\ge 0}$ and the order on $\bbQ$, not the real numbers $\bbR$.
\end{definition}
